# Features

This section documents the features of Tabular Editor.

## In this section

### DAX Features
- @dax-debugger - Step through the evaluation of a DAX expression
- @dax-editor - Code editor for DAX expressions, queries and scripts
- @dax-query - Write and run DAX queries
- @dax-scripts - Edit the DAX of multiple objects in one document
- @code-actions - Code improvements and refactorings suggested in the editor
- @dax-package-manager - Install and manage DAX packages

### Scripting and Automation
- @csharp-scripts - C# scripting overview
- C# Script Library
  - @csharp-script-library
  - @script-library-beginner
  - @script-library-advanced
- @script-helper-methods - Built-in helper methods for scripts
- @useful-script-snippets - Common script examples
- @macros - Save scripts as macros

### Model Analysis and Quality
- @best-practice-analyzer - Model quality analysis and rules
  - @using-bpa - How to use the Best Practice Analyzer
  - @using-bpa-sample-rules-expressions - Example BPA rules
- @dax-optimizer-integration - DAX Optimizer integration

### Data Exploration and Connectivity
- @import-tables - Table import functionality
- @connectivity - Data source connectors and authentication
  - @connect-sql-server, @connect-snowflake, @connect-databricks, @connect-oracle
  - @connect-odbc, @connect-oledb, @connect-onelake, @connect-dataflows
- @table-preview - Browse the rows of a table
- @pivot-grid - Browse model data in a pivot table
- @semantic-model-types
  - @direct-lake-sql-model
  - @dq-over-as-limitations

### AI Features
- @ai-assistant - Chat-based model development with your own AI provider key
- @mcp-server - Connect an external agent, such as Claude Code, GitHub Copilot or Cursor, to the open model
- @ai-audit-log - Log of actions taken by the AI Assistant and the MCP server

### Advanced Modelling Features
- @user-context-calculated-columns - Calculated columns evaluated per user and the objects that can reference them
- @metadata-translation-editor - Multi-language support
- @perspective-editor - Managing model perspectives

### Model Organization
- @hierarchical-display - Object tree navigation and organization
- @table-groups - Organizing tables in logical groups

### Model Deployment and Management
- @supported-files - File format support
- [Model deployment](deployment.md) - Deployment options and strategies
- @workspace-databases - Working with workspace databases
- @workspace-mode - Synchronize a model file with a workspace database
- @tmdl - Tabular Model Definition Language support
- @save-to-folder - Serialize models to folder structures
- @auto-reload - Reload the model when its files change on disk

### Command Line and Integration
- @command-line-options - CLI usage and automation

### Semantic Bridge for cross-platform translations
- @semantic-bridge - Semantic Bridge overview
- @semantic-bridge-metric-view-validation - Validation rules system for Metric Views
