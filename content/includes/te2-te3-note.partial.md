> [!NOTE]
> This page covers Tabular Editor 2, the free, open-source version of Tabular Editor. Tabular Editor 3 is the commercial version. It adds a DAX editor with auto-complete, [DAX queries](xref:dax-query), table preview, diagrams, the [DAX debugger](xref:dax-debugger) and [VertiPaq Analyzer](https://www.sqlbi.com/tools/vertipaq-analyzer/) integration. @migrate-from-te2 compares the two products feature by feature.
>
> Tabular Editor 3 has an [MCP server](xref:mcp-server) that lets AI agents such as Claude Code, GitHub Copilot, Codex and Cursor read, query and change the open model.
>
> First-time users get a [free 30-day trial of Tabular Editor 3](https://tabulareditor.com/why-tabular-editor) with the Enterprise Edition feature set. The trial needs a valid e-mail address and no credit card. See [Requesting a trial license](xref:getting-started#requesting-a-trial-license).
