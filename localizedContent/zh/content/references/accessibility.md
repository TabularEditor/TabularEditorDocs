# 辅助功能

Tabular Editor 3 中的大多数辅助功能设置都位于 **工具 > 偏好 > Tabular Editor > 用户界面** 页面。参见 [偏好](xref:preferences)。

## 色觉障碍模式

[未保存的更改](xref:unsaved-changes)和模型比较视图会将新增对象标记为绿色、已删除对象标记为红色、已编辑对象标记为橙色。当你在 **工具 > 偏好 > Tabular Editor > 用户界面** 下的 **辅助功能** 组中选择 **色盲模式** 时，新增对象会标记为青绿色，而已删除和已编辑对象会保留原有颜色。

**色盲模式** 默认关闭，会按每个 Windows 用户单独保存，并应用于 TOM Explorer 和模型比较视图中的行底色和图标徽章。

## 键盘快捷键

在 **工具 > 偏好 > Tabular Editor > 键盘** 下，你可以为命令分配自己的快捷键，也可以查看已分配的快捷键；@shortcuts3 列出了默认快捷键。

## 显示缩放

Tabular Editor 会遵循 Windows 中 **设置 > 系统 > 显示** 下配置的显示缩放。

## 主题

Tabular Editor 3 提供了多种主题，包括深色主题，你可以在 **窗口 > 主题** 中选择它们（参见 [更改主题和调色板](xref:user-interface#changing-themes-and-palettes)）。

## 语言

在 **工具 > 偏好 > Tabular Editor > 用户界面** 下的 **语言** 组中选择界面语言。重启 Tabular Editor 后，更改将生效。参见 @personalizing-te3。

## 报告无障碍问题

通过 **帮助 > 社区支持** Report 辅助功能问题；如果你的许可证包含该服务，也可以通过 **帮助 > 专属支持** Report 辅助功能问题。
