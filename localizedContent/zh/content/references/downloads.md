# Tabular Editor 3 下载

本页面提供 Tabular Editor 3 的下载和安装说明。

## 最新版本

Tabular Editor 3.27.1.1 (*[发布说明](release-notes/3_27_1_1.md)*) 以两个版本发布，一个基于 .NET 10，另一个基于 .NET 8。这两个版本在*功能上完全相同*。安装一个版本会替换另一个版本；请参阅[在 .NET 8 和 .NET 10 包之间切换](xref:installation-activation-basic#switching-between-the-net-8-and-net-10-packages)。

### 基于 .NET 10（推荐）

需要 [.NET Desktop Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0)。`.exe` 安装程序会为您下载并安装；便携式 `.zip` 是自包含的，完全不需要运行时。

- 下载 [Tabular Editor 3.27.1.1（64 位）](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.Installer.x64.Net10.exe) *（推荐）*
- 下载 [Tabular Editor 3.27.1.1 (ARM64)](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.Installer.ARM64.Net10.exe)
- 便携版： [x64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.x64.Net10.zip)、[ARM64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.ARM64.Net10.zip)
- MSI 版本：[x64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.x64.Net10.msi)、[ARM64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.ARM64.Net10.msi)

### 在 .NET 8 上

适用于尚无法运行 .NET 10 桌面运行时的计算机。需要 [.NET Desktop Runtime 8](https://dotnet.microsoft.com/download/dotnet/8.0)。

- 下载 [Tabular Editor 3.27.1.1（64 位）](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.Installer.x64.Net8.exe)
- 下载 [Tabular Editor 3.27.1.1 (ARM64)](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.Installer.ARM64.Net8.exe)
- 便携版：[x64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.x64.Net8.zip)、[ARM64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.ARM64.Net8.zip)
- MSI 版本：[x64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.x64.Net8.msi)、[ARM64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.ARM64.Net8.msi)

> [!TIP]
> 不确定选择哪个版本？请选择 .NET 10 x64 安装程序。仅在基于 ARM 的电脑上选择 ARM64，并且仅在您的组织无法安装 .NET 10 桌面运行时时选择 .NET 8。

请参阅@system-requirements，了解完整的兼容性矩阵，并参阅@release-history，了解此版本和所有先前版本的版本说明。

## 安装说明

1. 下载 .exe 安装程序文件。
2. 运行 .exe 安装程序。安装向导将引导您完成安装。
3. 有关如何激活产品或更改许可证密钥的说明，请参阅我们的[入门指南](xref:getting-started)。

升级到较新版本的 Tabular Editor 3 时，无需卸载之前的安装。
