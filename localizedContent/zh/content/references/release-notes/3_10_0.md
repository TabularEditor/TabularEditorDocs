### 先决条件

Tabular Editor 3.3.0 (and newer) uses .NET 6. 在启动 Tabular Editor 3.3.0（或更高版本）之前，你可能需要先安装[适用于桌面的.NET 6.0 运行时](https://dotnet.microsoft.com/en-us/download/dotnet/6.0/runtime)。 Starting from 3.3.1, the Tabular Editor 3 installer will download and install these prerequisites, if they are missing.

## 3.10.0 新增功能

阅读我们的[发布博文](https://blog.tabulareditor.com/2023/08/23/tabular-editor-3-august-2023-release/)，快速了解本次发布中最重要的更新。

- Tabular Editor 现已支持通过“导入表向导”向 [Direct Lake Dataset](https://learn.microsoft.com/en-us/power-bi/enterprise/directlake-overview) 添加表。 Moreover, you can update the schema of existing tables the usual way. Tabular Editor utilises the [SQL endpoint of your Fabric Lakehouse](https://learn.microsoft.com/en-us/fabric/data-engineering/lakehouse-sql-endpoint) to obtain the table schemas. We've also published a [blog post on DirectLake, if you want to learn more](https://blog.tabulareditor.com/2023/08/23/fabric-direct-lake-dataset/).

> [!NOTE]
> 此版本的 Tabular Editor 允许你在已具有 Direct Lake 连接的模型中导入表或更新表架构。 The Import Table Wizard does not yet support creating a new Direct Lake connection on an empty model. This will be added in a future release.

> [!WARNING]
> 一旦你通过 XMLA endpoint 对 Direct Lake Dataset 进行任何更改，你将[无法再在 Fabric 的 Web 建模功能中打开该 Dataset](https://learn.microsoft.com/en-us/power-bi/enterprise/directlake-overview#enable-xmla-read-write:~:text=Direct%20Lake%20datasets%20created%20or%20modified%20by%20using%20XMLA%2Dbased%20tools%20cannot%20be%20opened%20in%20the%20Web%20modelling%20feature.)。

- C# Script 现已支持[预处理器指令](xref:csharp-scripts#compatibility)，用于判断你正在使用的 Tabular Editor 版本。 This allows you to write scripts that are compatible with both Tabular Editor 2 and Tabular Editor 3.

## 3.10.0 改进内容

- 我们现在使用最新版本的 [AMO/TOM](https://www.nuget.org/packages/Microsoft.AnalysisServices.NetCore.retail.amd64/)。 This update adds support for Binary XML, which should help speed up XMLA operations. More details in this [Microsoft blog post](https://powerbi.microsoft.com/en-us/blog/improving-the-communication-performance-of-xmla-based-tools/).
- 我们还将 [TMDL 更新到 preview-3](https://www.nuget.org/packages/Microsoft.AnalysisServices.Tabular.Tmdl.NetCore.retail.amd64/19.65.12.3-TmdlPreview)，其中包含多项错误修复。

> [!NOTE]
> TMDL 仍处于预览阶段，因此该功能也应视为 Tabular Editor 3 的预览功能。 Make sure to keep a Model.bim / Database.json backup of your model metadata to avoid losing work.

- 在克隆对象时，我们现在会添加后缀“-Copy”，而不是“ Copy”，以降低对象名称末尾留下多余空格的风险，详见 [#940](https://github.com/TabularEditor/TabularEditor3/issues/940)。
- 自动完成弹出窗口现在会自动调整宽度，以适配其中最宽的条目。 See [#965](https://github.com/TabularEditor/TabularEditor3/issues/965).
- 当为 Power BI Desktop 模型保存备份 .bim 文件时，我们现在会使用 .pbix 文件名，而不是数据库 GUID。参见 [#958](https://github.com/TabularEditor/TabularEditor3/issues/958)。
- 表格预览性能改进。

## 3.10.0 中的错误修复

- 修复了使用“保存到文件夹”时，同义词（语言学元数据）无法保存的问题。
- 修复了备份 .bim 文件时间戳不正确的问题，参见 [#967](https://github.com/TabularEditor/TabularEditor3/issues/967)。
- 修复了当备份保存因任何原因失败时，用户无法取消部署的问题。
- 表格预览中的“查找”面板现在会在后台生成有效的 DAX 搜索表达式，参见 [#955](https://github.com/TabularEditor/TabularEditor3/issues/955)。
- 修复了当光标放在 DAX 函数上时，“转到定义（F12）”操作会被禁用的问题，参见 [#962](https://github.com/TabularEditor/TabularEditor3/issues/962)。
- 修复了在某些情况下无法从 .vpax 文件加载模型的问题。
- DAX 查询中的“结果计数”面板高度现在会自动调整以适配其内容。
- 属性网格现在能正确显示以一个或多个换行符开头的多行表达式，效果与在网格内编辑表达式时一致。
- 修复了一个问题：当从远程模型中删除已添加到 Pivot Grid 的列时，Pivot Grid 可能会陷入无限错误消息循环。
- 修复了一个问题：添加到菜单栏的宏在重启 Tabular Editor 后会停止工作。
- 修复了一个问题：对源自同一源表的多张表执行架构更新时，除其中一张外其余都会失败。

## 从 Tabular Editor 2.x 迁移过来？

观看[此视频](https://www.youtube.com/watch?v=pt3DdcjfImY)，以了解 Tabular Editor 3 的新功能。 Also, make sure to check our [onboarding guide](https://docs.tabulareditor.com/getting-started/index.html).

**Tabular Editor 3 主要功能概览：**

- 完全可自定义的 IDE，支持多显示器、Hi-DPI 和主题
- 全新强大的 DAX 代码编辑器，具备自动完成、语法检查、代码折叠等众多功能
- \*工作区模式，让你可以将更改保存到磁盘，并同时将模型元数据同步到 Analysis Services
- \*以无限滚动方式预览表数据、创建 PivotGrids，或编写 DAX 查询来浏览模型或测试计算逻辑
- \*计划数据刷新
- 针对 Provider 和 Structured数据源更新表架构（没错，连 M 查询也支持！）
- 创建 Data model 图示
- 创建 DAX脚本，让你在单个文档中编辑多个度量值或其他计算对象
- 录制 C# Script 并保存为宏（以前称为“Custom Actions”）
- 集成 VertiPaq分析器
- DAX调试器

\*=仅在连接到 Analysis Services 或 Power BI 实例时可用
