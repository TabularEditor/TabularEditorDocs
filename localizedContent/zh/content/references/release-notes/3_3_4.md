## 重要提示！

**注意**：Tabular Editor 3.3.0（及更新版本）使用 .NET 6。您可能需要先安装[.NET 6.0 Runtime for Desktop](https://dotnet.microsoft.com/en-us/download/dotnet/6.0/runtime)，然后才能启动 Tabular Editor 3.3.0（或更高版本）。从 3.3.1 开始，如果缺少这些先决条件，Tabular Editor 3 安装程序将下载并安装这些先决条件。

## 3.3.4 中的改进

- 将 TOM 更新至 [19.46.0](https://www.nuget.org/packages/Microsoft.AnalysisServices.NetCore.retail.amd64) 版本。
- 将 Microsoft.Data.SqlClient 更新至 [5.0.0](https://www.nuget.org/packages/Microsoft.Data.SqlClient) 版本。
- 将 SciLexer.dll 更新至 4.4.6 版本，该版本不受[此 CVE](https://cve.mitre.org/cgi-bin/cvename.cgi?name=2019-16294)的影响。
- 多项小修小改和改进。
- “新建/编辑关系”对话框改进：列按字母顺序和匹配类型排序。我们现在还会根据“源列”的名称建议“目标列”。
- 将新 Power BI 数据集的默认 CL 更改为 1571，并添加了对 [ObjectTranslation.Altered](https://docs.microsoft.com/en-us/dotnet/api/microsoft.analysisservices.tabular.objecttranslation.altered?view=analysisservices-dotnet) 属性的支持，该属性应设置为“true”，以防止在对 AS 数据集创建 DirectQuery 时元数据翻译被源覆盖。
- 添加了用于保存当前模型的新快捷键 **Ctrl+Alt+S**。请参阅[#595](https://github.com/TabularEditor/TabularEditor3/issues/595)、[#561](https://github.com/TabularEditor/TabularEditor3/issues/561)。
- 添加了用于调试逗号 DAX 格式的快捷键 **Ctrl+Shift+F6**。请参阅[#595](https://github.com/TabularEditor/TabularEditor3/issues/595 )。
- 当服务器名称和数据库名称等参数存储在共享 M 表达式中时，离线架构检测现在应该可以正常工作。

## 3.3.4 中的错误修复

- 修复了“更新表架构”选项将所有列报告为已删除的问题，请参阅 [#612](https://github.com/TabularEditor/TabularEditor3/issues/612)。
- 修复了使用嵌套筛选器表达式时出现的语义分析器误报错误。
- 修复在使用“NATURALINNERJOIN”/“NATURALLEFTOUTERJOIN”时，对于通过关系而非公共列联接的表格，语义分析器报告的错误。
- 修复了尝试显示 ODBC 连接器的连接对话框时出现的问题，请参阅 [#448](https://github.com/TabularEditor/TabularEditor3/issues/448)
- 使用 Microsoft.Data.SqlClient 进行 AAD 身份验证现在会显示模式弹出窗口（而不是打开操作系统浏览器）
- 修复了 SQL Server 连接对话框“高级按钮”有时导致崩溃的问题。
- 表格导入向导现在允许在 Azure Synapse 上预览数据（不再将 NOLOCK 提示添加到数据预览查询中）
- 32 位安装程序现在应能正确检查 32 位 .NET Desktop Runtime
- DAX 自动补全现在还可以建议 Variant 类型的标量变量，请参阅 [#615](https://github.com/TabularEditor/TabularEditor3/issues/615)
- 修复了 DAX 调试器无法显示包含嵌套条件分支的局部/监视表达式的问题。
- 将 SciLexer.dll 包含在应用程序文件夹中，而不是将其提取/加载到 %LocalAppData%\Temp。应能避免有时在组策略阻止从该位置加载 DLL 时出现的“调用目标引发了异常”错误。
- 修复了属性网格无法对多项选择设置嵌套属性的问题。请参阅[#614](https://github.com/TabularEditor/TabularEditor3/issues/614)。
- 修复了属性网格未刷新以显示动态添加/删除的属性的问题，例如在切换“增量刷新策略”属性时。
- 修复了 AAS 开发人员层实例被视为标准层实例的问题，从而避免了与 TE3 Business Edition 的连接问题。
- 修复了 NAMEOF 自动补全在某些情况下未显示所有列/Measure 引用的问题，请参阅 [#620](https://github.com/TabularEditor/TabularEditor3/issues/620)。
- 修复了某些 DAX 关键字（START、ORDER、RETURN 等）在不加引号用作表引用时未被视为错误的问题。此漏洞还导致无法正确格式化包含对此类表格的带引号引用代码。
- 修复了“4096 (0x1000) 是无效的区域设置标识符”问题，请参阅 [#576](https://github.com/TabularEditor/TabularEditor3/issues/576)。
- 防止查找/替换搜索崩溃，请参阅 [#611](https://github.com/TabularEditor/TabularEditor3/issues/611)。
- 在只读模式下显示所有属性，请参阅 [#596](https://github.com/TabularEditor/TabularEditor3/issues/596)。
- 移除了固定/取消固定窗口的动画，请参阅 [#595](https://github.com/TabularEditor/TabularEditor3/issues/595)。
- 不要在 DAX 注释中自动添加大括号，请参阅 [#597](https://github.com/TabularEditor/TabularEditor3/issues/597)。
- 修复了默认 CL 值在设置为非标准值时导致“偏好”对话框崩溃的问题。

## 来自 Tabular Editor 2.x？

观看[此视频](https://www.youtube.com/watch?v=pt3DdcjfImY)，了解 Tabular Editor 3 的新功能。此外，请务必查看我们的[入门指南](https://docs.tabulareditor.com/onboarding/index.html)。

**Tabular Editor 3 主要功能概览：**
- 完全可自定义的 IDE，支持多显示器、高 DPI 和主题
- 全新的强大 DAX 代码编辑器，具备自动完成、语法检查、代码折叠等众多功能
- *工作区模式，允许您将更改保存到磁盘，并同时将模型元数据同步到 Analysis Services
- *使用无限滚动预览表格数据，创建数据透视网格或编写 DAX 查询以浏览模型或测试计算逻辑
- *安排数据刷新
- 更新提供程序和结构化数据源上的表格架构（是的，即使对于 M 查询也是如此！）
- 创建数据模型图
- 创建 DAX 脚本，让您能够在单个文档中编辑多个度量值或其他计算对象
- 录制 C# 脚本并另存为宏（以前称为“自定义操作”）
- VertiPaq分析器集成
- *DAX 调试器

*=仅在连接到 Analysis Services 或 Power BI 实例时
