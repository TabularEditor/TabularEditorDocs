## 3.1.6 中的改进

- DAX编辑器改进：
  - **Offline DAX formatting now available**. “Format DAX” 按钮和快捷键（F6）现在使用内置 DAX 格式化器，而不是 www.daxformatter.com。 The built-in formatter has a few more configuration options and also fixes column and measure references that do not follow best practices, and more. Since the built-in formatter does not perform a web request, it is also significantly faster. If you encounter an issue with the built-in formatter, you can disable it by enabling the \*\*Use daxformatter.com instead of built-in formatter" under **Tools > Preferences > DAX Editor**.
  - You can now configure keywords/functions to be formatted with different casing, based on your preferences. 相关设置位于 **Tools > 偏好 > DAX编辑器 > Auto Formatting**，参见 [#58](https://github.com/TabularEditor/TabularEditor3/issues/58)。 [More details](xref:personalizing-te3#dax-settings).
  - 为 DAX 查询新增“Debug comma” 格式化选项（将所有逗号放在行首，便于给子表达式加注释/取消注释），参见 [#96](https://github.com/TabularEditor/TabularEditor3/issues/96)。
  - 现在你可以选中整个对象引用（度量值、列等）， by double-clicking on it (previously, only the word under the cursor would get selected).
  - 选中子表达式后输入左括号（圆括号或花括号），系统会自动用匹配的右括号将所选内容包裹起来，参见 [#48](https://github.com/TabularEditor/TabularEditor3/issues/48)。
  - 编写注释时，Code Assist 不再干扰。
- TE3 现可从 Snowflake 导入并更新表架构（仅限 Power BI Data model）。
- 已将 TOM 更新至 19.27.2.1
- 现已提供 C# Script 方法 `SelectObjects`，可根据对象列表提示用户选择一个或多个对象。
- New option, **Tools > Preferences > TOM Explorer > Show full branch**. When this is checked, filtering the TOM Explorer will also show all child objects, even when they do not match the filter string. See [#276](https://github.com/TabularEditor/TabularEditor3/issues/276).
- New option, **Tools > Preferences > TOM Explorer > Always show delete warnings**. When this is checked, all delete operations will display a confirmation dialog. When unchecked, only multi-select deletions and deletion of objects referenced by other objects will display the confirmation dialog (remember, every operation can be undone in Tabular Editor). See [#10](https://github.com/TabularEditor/TabularEditor3/issues/10).
- Added the "Apply Refresh Policy" menu option on tables, when applicable. 更多信息见 [使用 Tabular Editor 配置增量刷新](https://www.youtube.com/watch?v=icCGFG6KpIA)，另见 [#291](https://github.com/TabularEditor/TabularEditor3/issues/291)。
- 已将 DAX 依赖关系视图添加到 **视图** 菜单，并新增一个复选框，使该视图可跟踪 TOM Explorer 中的当前所选项，参见 [#10](https://github.com/TabularEditor/TabularEditor3/issues/10)。

## 3.1.6 问题修复

- “偏好”、“SelectItems”和“保存/编辑宏”对话框现已支持调整大小，参见 [#51](https://github.com/TabularEditor/TabularEditor3/issues/51)。
- 当针对使用原生查询导入数据的 Power BI Desktop 模型执行“更新表架构”操作时，我们会将 Power BI Desktop 实例置于前台，因为 Desktop 会弹出需要确认的对话框，确认后“更新表架构”操作才能完成。参见问题 [#55](https://github.com/TabularEditor/TabularEditor3/issues/55)。
- Taskbar icon should no longer break when upgrading. See[#163](https://github.com/TabularEditor/TabularEditor3/issues/163).
- When updating table schemas, you will now be shown a connection dialog that allows you to change the auth mode. See[#262](https://github.com/TabularEditor/TabularEditor3/issues/262).
- 现在仅在将模型部署到 Azure AS 或 Power BI 时，才会自动移除角色成员属性 `MemberId`。 See [#263](https://github.com/TabularEditor/TabularEditor3/issues/263).
- 修复了在排队多个刷新操作时 UI 冻结的问题，参见 [#281](https://github.com/TabularEditor/TabularEditor3/issues/281)。
- AAD 对象选择器现在会生成格式正确的对象名称。 See[#286](https://github.com/TabularEditor/TabularEditor3/issues/286).
- 执行用于创建计算组的 DAX 脚本时，现在会正确分配序号，参见 [#296](https://github.com/TabularEditor/TabularEditor3/issues/296)。
- 现在可以使用 CTRL + 方向键展开/折叠 TOM Explorer 中的所有节点，类似 TE 2.x，参见 [#297](https://github.com/TabularEditor/TabularEditor3/issues/297)。
- 执行创建计算组的 DAX 脚本时，列名现在会被正确赋值，参见 [#298](https://github.com/TabularEditor/TabularEditor3/issues/298)。
- 修复了在美国/非美国模式之间切换时，DAX 脚本区域设置未能正确更新的问题。
- 修复了尝试连接到包含未设置兼容级别的数据库的 AS 服务器时可能发生的崩溃（当连接到与 Analysis Services 多维实例共享其数据目录的 Analysis Services 表格实例时会出现）。
- 修复了一个有时会导致“更新表架构”功能 Report 所有列均在源中缺失的问题。
- 修复了在使用模拟身份时，表格预览功能可能导致网格列配置不正确的问题。
- 修复了保存模型时语义更改通知栏不消失的问题。
- 修复了保存模型时属性网格中的编辑不会自动提交的问题。

## 从 Tabular Editor 2.x 升级而来？

观看[此视频](https://www.youtube.com/watch?v=pt3DdcjfImY)，快速了解 Tabular Editor 3 的新功能。

**Tabular Editor 3 主要功能概览：**

- 完全可自定义的 IDE，支持多显示器、Hi-DPI 以及主题
- 全新强大的 DAX 代码编辑器，支持自动补全、语法检查、代码折叠等，还有更多功能
- \*工作区模式：可将更改保存到磁盘，并同时将模型元数据同步到 Analysis Services
- \*可通过无限滚动预览表数据，创建 PivotGrid，或编写 DAX 查询来浏览模型并测试计算逻辑
- \*安排数据刷新
- 支持更新提供程序数据源和 Structured数据源的表架构（没错，连 M 查询也支持！）
- 创建 Data model 示意图
- 创建 DAX 脚本，让你在单个文档中编辑多个度量值或其他计算对象
- 录制 C# Script，并保存为宏（以前称为“Custom Actions”）
- 集成 VertiPaq分析器

\*=只在连接到 Analysis Services 或 Power BI 实例时可用
