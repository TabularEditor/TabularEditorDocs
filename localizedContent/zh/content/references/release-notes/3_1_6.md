## 3.1.6 中的改进

- DAX编辑器改进：
  - **现已支持离线 DAX 格式化**。 “Format DAX” 按钮和快捷键（F6）现在使用内置 DAX 格式化器，而不是 www.daxformatter.com。内置格式化程序提供了更多配置选项，还会修正不符合最佳做法的列和度量值引用等问题。由于内置格式化程序不会发出 Web 请求，因此速度也明显更快。如果你在使用内置格式化程序时遇到问题，可以在 **工具 > 偏好 > DAX编辑器** 下启用 **Use daxformatter.com instead of built-in formatter** 来将其禁用。
  - 现在，你可以根据自己的偏好，将关键字和函数格式化为不同的大小写形式。相关设置位于 **Tools > 偏好 > DAX编辑器 > Auto Formatting**，参见 [#58](https://github.com/TabularEditor/TabularEditor3/issues/58)。[更多详细信息](xref:personalizing-te3#dax-settings)。
  - 为 DAX 查询新增“Debug comma” 格式化选项（将所有逗号放在行首，便于给子表达式加注释/取消注释），参见 [#96](https://github.com/TabularEditor/TabularEditor3/issues/96)。
  - 现在你可以选中整个对象引用（度量值、列等），双击即可选中（此前只能选中光标所在的单词）。
  - 选中子表达式后输入左括号（圆括号或花括号），系统会自动用匹配的右括号将所选内容包裹起来，参见 [#48](https://github.com/TabularEditor/TabularEditor3/issues/48)。
  - 编写注释时，Code Assist 不再干扰。
- TE3 现可从 Snowflake 导入并更新表架构（仅限 Power BI Data model）。
- 已将 TOM 更新至 19.27.2.1
- 现已提供 C# Script 方法 `SelectObjects`，可根据对象列表提示用户选择一个或多个对象。
- 新增选项：**工具 > 偏好 > TOM Explorer > 显示完整分支**。选中后，筛选 TOM Explorer 时还会显示所有子对象，即使它们不匹配筛选字符串。参见 [#276](https://github.com/TabularEditor/TabularEditor3/issues/276)。
- 新增选项：**工具 > 偏好 > TOM Explorer > 始终显示删除警告**。选中后，所有删除操作都会显示确认对话框。未选中时，只有多选删除以及删除被其他对象引用的对象时才会显示确认对话框（请记住，在 Tabular Editor 中，每项操作都可以撤销）。参见 [#10](https://github.com/TabularEditor/TabularEditor3/issues/10)。
- 在适用情况下，已在表上新增“应用刷新策略”菜单选项。更多信息见 [使用 Tabular Editor 配置增量刷新](https://www.youtube.com/watch?v=icCGFG6KpIA)，另见 [#291](https://github.com/TabularEditor/TabularEditor3/issues/291)。
- 已将 DAX 依赖关系视图添加到 **视图** 菜单，并新增一个复选框，使该视图可跟踪 TOM Explorer 中的当前所选项，参见 [#10](https://github.com/TabularEditor/TabularEditor3/issues/10)。

## 3.1.6 问题修复

- “偏好”、“SelectItems”和“保存/编辑宏”对话框现已支持调整大小，参见 [#51](https://github.com/TabularEditor/TabularEditor3/issues/51)。
- 当针对使用原生查询导入数据的 Power BI Desktop 模型执行“更新表架构”操作时，我们会将 Power BI Desktop 实例置于前台，因为 Desktop 会弹出需要确认的对话框，确认后“更新表架构”操作才能完成。参见问题 [#55](https://github.com/TabularEditor/TabularEditor3/issues/55)。
- 升级后，任务栏图标不再会失效。参见 [#163](https://github.com/TabularEditor/TabularEditor3/issues/163)。
- 更新表架构时，现在会显示一个连接对话框，让你可以更改身份验证模式。参见 [#262](https://github.com/TabularEditor/TabularEditor3/issues/262)。
- 现在仅在将模型部署到 Azure AS 或 Power BI 时，才会自动移除角色成员属性 `MemberId`。参见 [#263](https://github.com/TabularEditor/TabularEditor3/issues/263)。
- 修复了在排队多个刷新操作时 UI 冻结的问题，参见 [#281](https://github.com/TabularEditor/TabularEditor3/issues/281)。
- AAD 对象选择器现在会生成格式正确的对象名称。参见 [#286](https://github.com/TabularEditor/TabularEditor3/issues/286)。
- 执行用于创建计算组的 DAX 脚本时，现在会正确分配序号，参见 [#296](https://github.com/TabularEditor/TabularEditor3/issues/296)。
- 现在可以使用 CTRL + 方向键展开/折叠 TOM Explorer 中的所有节点，类似 TE 2.x，参见 [#297](https://github.com/TabularEditor/TabularEditor3/issues/297)。
- 执行创建计算组的 DAX 脚本时，列名现在会被正确赋值，参见 [#298](https://github.com/TabularEditor/TabularEditor3/issues/298)。
- 修复了在美国/非美国模式之间切换时，DAX 脚本区域设置未能正确更新的问题。
- 修复了尝试连接到包含未设置兼容级别的数据库的 AS 服务器时可能发生的崩溃（当连接到与 Analysis Services 多维实例共享其数据目录的 Analysis Services 表格实例时会出现）。
- 修复了一个有时会导致“更新表架构”功能 Report 所有列均在源中缺失的问题。
- 修复了在使用模拟身份时，表格预览功能可能导致网格列配置不正确的问题。
- 修复了保存模型时语义更改通知栏不消失的问题。
- 修复了保存模型时属性网格中的编辑不会自动提交的问题。

## 从 Tabular Editor 2.x 升级而来？

观看[此视频](https://www.youtube.com/watch?v=pt3DdcjfImY)，快速了解 Tabular Editor 3 的新功能。

**Tabular Editor 3 主要功能概览：**

- 完全可自定义的 IDE，支持多显示器、Hi-DPI 以及主题
- 全新强大的 DAX 代码编辑器，支持自动补全、语法检查、代码折叠等，还有更多功能
- \*工作区模式：可将更改保存到磁盘，并同时将模型元数据同步到 Analysis Services
- \*可通过无限滚动预览表数据，创建 PivotGrid，或编写 DAX 查询来浏览模型并测试计算逻辑
- \*安排数据刷新
- 支持更新提供程序数据源和 Structured数据源的表架构（没错，连 M 查询也支持！）
- 创建 Data model 示意图
- 创建 DAX 脚本，让你在单个文档中编辑多个度量值或其他计算对象
- 录制 C# Script，并保存为宏（以前称为“Custom Actions”）
- 集成 VertiPaq分析器

\*=只在连接到 Analysis Services 或 Power BI 实例时可用
