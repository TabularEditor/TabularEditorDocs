## 3.1.2 中的错误修复

- 修复了“更新表架构”对 SQL DW/Synapse SQL 池数据源不起作用的问题，请参阅 [#231](https://github.com/TabularEditor/TabularEditor3/issues/231)。
- 修复了 Best Practice Analyzer 仍会考虑已忽略规则的问题，请参阅 [#203](https://github.com/TabularEditor/TabularEditor3/issues/203)。
- 修复了由于 JSON 序列化错误而无法将模型保存到磁盘（文件或文件夹）的问题，请参阅[#232](https://github.com/TabularEditor/TabularEditor3/issues/232)。
- 修复了在检查结构化数据源的属性值时导致崩溃的问题。

## 3.1.1 中的改进

- 共享表达式（Power Query/M 表达式）现在可以序列化为单个文件。您可以在**工具 > 首选项 > 保存到文件夹**下控制序列化，或在**模型 > 序列化选项…**下为现有模型控制序列化（[#218](https://github.com/TabularEditor/TabularEditor3/issues/218)）。
- 新增选项，用于控制如何将透视成员资格应用于**工具 > 首选项 > 建模操作**下的新对象（请参阅问题 [#216](https://github.com/TabularEditor/TabularEditor3/issues/216))。
- 现在可以将“PrivacySetting”属性从序列化中排除，以避免出现 Microsoft.AnalysisServices.Deployment 相关问题。这在**模型 > 序列化选项...**下进行控制（请参阅问题[#210](https://github.com/TabularEditor/TabularEditor3/issues/210))。
- 您现在可以直接在 C# 脚本中定义枚举、结构和类，从而使 C# 代码的结构化和重用更加容易。
- VertiPaq Analyzer 现在提供了一个从数据收集统计信息的选项（**工具 > 首选项 > VertiPaq Analyzer**），从而提高了统计信息的质量，例如当列的 IsAvailableInMDX = false 时。请参阅问题 [#190](https://github.com/TabularEditor/TabularEditor3/issues/290)。
- 创建新模型时，Tabular Editor 3 现在会在首次保存时提示是否应将模型保存为文件或文件夹。您还可以在**工具 > 首选项 > 常规 > 新模型的默认保存格式**下设置默认模式。请参阅问题 [#50](https://github.com/TabularEditor/TabularEditor3/issues/50)。
- 提高了启动性能（一些用户报告称，通过将“-multicorejit”开关添加到 TabularEditor3.exe 快捷方式，进一步缩短了启动时间）。
- 重新设计了“模型”菜单，使“新建计算组”等选项易于使用。
- 将 AMO/TOM 客户端库更新为 [19.26.1.7](https://www.nuget.org/packages/Microsoft.AnalysisServices.retail.amd64/)。
- 现在，可以在最佳实践分析器中单独迭代模型角色成员。
- “窗口”菜单中的“工作区”已重命名为“布局”，以避免与[工作区模式](https://docs.tabulareditor.com/te3/tutorials/workspace-mode.html)混淆。
- 添加了 Ctrl+Shift+D 作为“部署”的快捷键
- 支持新的 DAX 函数（['HASH'](https://dax.guide/hash)、['NAMEOF'](https://dax.guide/nameof)、['COLUMNSTATISTICS'](https://dax.guide/columnstatistics)、['BITAND'](https://dax.guide/bitand)、['BITLSHIFT'](https://dax.guide/bitlshift)、['BITOR'](https://dax.guide/bitor)、['BITRSHIFT'](https://dax.guide/bitrshift)、['BITXOR'](https://dax.guide/bitxor))，并支持 ['SELECTCOLUMNS'](https://dax.guide/selectcolumns) 中的可选列名参数。

## 3.1.1 中的错误修复

- 删除对象时，TOM 资源管理器不应再冻结或崩溃（请参阅问题 [#223](https://github.com/TabularEditor/TabularEditor3/issues/223)、[#209](https://github.com/TabularEditor/TabularEditor3/issues/209))。
- 修复了编辑器（[#207](https://github.com/TabularEditor/TabularEditor3/issues/207)）和图标（[#215](https://github.com/TabularEditor/TabularEditor3/issues/215)）中深色主题的颜色问题
- 表格现已在“创建/编辑关系”对话框中按字母顺序排序（请参阅问题 [#214](https://github.com/TabularEditor/TabularEditor3/issues/214)
- 修复了 C# 脚本无法保存为宏的问题（请参阅问题 [#208](https://github.com/TabularEditor/TabularEditor3/issues/208))。
- 修复了数据源密码/凭据未正确应用于工作区数据库的问题（请参阅问题 [#205](https://github.com/TabularEditor/TabularEditor3/issues/205)）。
- “选择所有列”复选框不应再导致崩溃（请参阅问题 [#204](https://github.com/TabularEditor/TabularEditor3/issues/204))。
- 当脚本引用外部 DLL 时（使用“#r”预编译器指令），Tabular Editor 现在始终会在安装目录中进行查找，请参阅问题 [#192](https://github.com/TabularEditor/TabularEditor3/issues/192)。
- 修复了语言架构的一个漏洞，该漏洞导致问答功能在某些情况下停止工作
- 在“数据预览”中对日期列进行筛选不再会导致崩溃
- 在 TOM Explorer 透视下拉列表中选择所有透视时，不再显示不包含在任何透视中的对象。还修复了下拉框不更新透视名称的问题。
- 允许将某些 DAX 关键字用作变量（“WEEK”、“DAY”、“INTEGER”等），且不会显示错误。
- 修复了首次保存模型时序列化选项未被存储的问题。
- 修复了 DAX 解析器的一个问题，该问题会导致在加载模型时发生崩溃（请参阅 [#229](https://github.com/TabularEditor/TabularEditor3/issues/229)）。

## 来自 Tabular Editor 2.x？

观看[此视频](https://www.youtube.com/watch?v=pt3DdcjfImY)，了解 Tabular Editor 3 的新功能。

**Tabular Editor 3 主要功能概览：**
- 完全可自定义的 IDE，支持多显示器、高 DPI 和主题
- 全新的强大 DAX 代码编辑器，具备自动完成、语法检查、代码折叠等众多功能
- *工作区模式，允许您将更改保存到磁盘，并同时将模型元数据同步到Analysis Services
- *使用无限滚动预览表格数据，创建数据透视网格或编写 DAX 查询以浏览模型或测试计算逻辑
- *安排数据刷新
- 更新提供程序和结构化数据源上的表格架构（是的，即使对于 M 查询也是如此！）
- 创建数据模型图
- 创建 DAX 脚本，让您能够在单个文档中编辑多个度量值或其他计算对象
- 录制 C# 脚本并保存为宏（以前称为“自定义操作”）
- VertiPaq Analyzer 集成

*=仅在连接到 Analysis Services 或 Power BI 实例时
