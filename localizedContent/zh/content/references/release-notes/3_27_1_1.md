## 3.27.1.1 中的错误修复

- 修复了在安全配置阻止代码编辑器组件启动的计算机上，当您选择带有表达式的对象时，Tabular Editor 3 意外退出的问题。此问题是自 3.27.0 以来的回归。管理员可以使用 `RequireNativeLibrarySignatureVerification` 策略重新启用代码编辑器库的签名检查。请参阅[策略](https://docs.tabulareditor.com/en/references/policies.html#general-policies )。
- 修复了在错误报告对话框和 `errorreport.txt` 中，意外错误的详细信息多次列出同一错误并遗漏根本错误的问题。现在，链中的每个错误都只列出一次，直至根本原因。

## 来自 Tabular Editor 2.x？

如需了解 Tabular Editor 3 的主要功能，请观看[此视频](https://youtu.be/O4ATwdzCvWc)。要开始使用，请参阅[入门指南](https://docs.tabulareditor.com/onboarding/index.html)。

**Tabular Editor 3 的主要功能：**
- 可定制的 IDE，支持多显示器和高 DPI，并提供主题
- 具备自动完成、语法检查、代码折叠和格式化功能的 DAX 代码编辑器
- *工作区模式，可将您的更改保存到磁盘，并同时将模型元数据同步到 Analysis Services
- *使用无限滚动预览表格数据，创建数据透视网格或编写 DAX 查询以浏览模型或测试计算逻辑
- *安排数据刷新
- 更新提供程序和 Structured 数据源上的表格架构，包括 M 查询
- 创建数据模型图
- 创建 DAX 脚本，以便在单个文档中编辑多个度量值或其他计算对象
- 录制 C# 脚本并将其保存为宏（原“自定义操作”）
- VertiPaq Analyzer 集成
- DAX 调试器
- DAX 优化器集成
- 用于重构您的 DAX 的代码操作

*=仅在连接到 Analysis Services 或 Power BI 实例时
