### 先决条件

Tabular Editor 3 uses .NET 6. 如果你用的是便携版，在启动 Tabular Editor 3 之前，你可能需要手动安装 [.NET 6.0 桌面运行时](https://dotnet.microsoft.com/en-us/download/dotnet/6.0/runtime)。

## 3.15.0 版本新增功能

查看我们的[发布博客](https://blog.tabulareditor.com/2024/04/24/tabular-editor-3-april-2024-release/)，快速了解本次版本中最重要的更新内容。

- We have a new **Preview** feature this month: **DAX Optimizer integration**. 如果你有 DAX优化器账号，就可以连接到你的 Workspace，上传 VPAX 文件，并直接在 Tabular Editor 中查看 [DAX优化器](https://daxoptimizer.com) 的结果。 [More information](https://docs.tabulareditor.com/features/dax-optimizer-integration.html).
- 我们现在支持在 DirectQuery 模式的分区中添加[数据覆盖定义表达式](https://learn.microsoft.com/en-us/analysis-services/tom/table-partitions?view=asallproducts-allversions#define-the-data-coverage-of-the-directquery-partition)。
- Tabular Editor 现在会在将元数据保存到磁盘时（保存为 Model.bim、Database.json 或 TMDL）向你的模型添加一个 `__TEdtr` 批注。 This annotation is used by Microsoft for analytics about Tabular Editor usage for semantic models published to a Power BI or Fabric workspace. This annotation may also be required for certain features to work correctly in Power BI / Fabric, when a model was edited using Tabular Editor.
- **新建模型** 对话框现在提供一个 **Direct Lake** 复选框\*，用于将模型配置为在 Fabric 中使用新的 Direct Lake 存储模式。 [More information](https://docs.tabulareditor.com/common/Datasets/direct-lake-dataset.html). Moreover, you can now explicitly choose the _Compatibility Mode_ when entering the _Compatibility Level_ manually.
- 你现在可以使用 Tabular Editor 导出[混淆的 VPAX 文件](https://www.sqlbi.com/blog/marco/2024/03/15/vpax-obfuscator-a-library-to-obfuscate-vpax-files/)。 This can be helpful when your metadata (object names and DAX expressions) are confidential, but you want to share the VPAX file with a person or service for optimization purposes. Find this option in the **VertiPaq Analyzer** view, on the dropdown next to the **Export** button.

## 3.15.0 改进内容

- We've updated [AMO/TOM to 19.79.1.1](https://www.nuget.org/packages/Microsoft.AnalysisServices.NetCore.retail.amd64). In this update, a bug that could sometimes cause overlapping policy range partitions to be generated, when invoking the "Apply Refresh Policy" option, has been fixed.
- 新建 Power BI / Fabric 模型的默认 _兼容级别_ 设为 1605。
- Direct Lake 模型初次部署时，我们现在会执行一次自动刷新，这是避免回退到 DirectQuery 的先决条件。 Moreover, there is a new option (which is enabled by default), to also perform an automatic refresh whenever a Direct Lake model is saved, when new tables have been added. This preference is located under **Tools > Preferences > Model Deployment > Data Refresh**.
- 在为 DAX 项生成脚本时新增排序选项：启用“按字母顺序排序脚本化项目”后，脚本中的所有 DAX 项都会按名称字母顺序排序。
- 新增六个编辑器命令及其默认键盘快捷键，用于在 DAX 编辑器中与可折叠代码区域交互：
  - `Editor.Dax.CollapseAllFolds`：折叠/关闭文档中的所有可折叠区域。 Default shortcut: **Ctrl+Alt+[**
  - `Editor.Dax.ExpandAllFolds`：展开/打开文档中的所有可折叠区域。 Default shortcut: **Ctrl+Alt+]**
  - `Editor.Dax.ToggleAllFolds`：在展开与折叠之间切换所有可折叠区域的状态；这可确保最终所有折叠区域处于相同状态。 Default shortcut: **Ctrl+Alt+;**
  - `Editor.Dax.CollapseFold`: collapse/close the foldable region that the cursor is currently positioned in. Default shortcut: **Ctrl+Shift+[**
  - `Editor.Dax.ExpandFold`：展开/打开光标当前所在的可折叠区域。 Default shortcut: **Ctrl+Shift+]**
  - `Editor.Dax.ToggleFold`: toggle the state of the foldable region that the cursor is in between the open and close states. Default shortcut: **Ctrl+Shift+;**
- DAX 编辑器现在支持在使用 **Ctrl+Backspace** 或 **Ctrl+Delete** 时，删除表/列/度量值引用中的单个词。 To delete the full reference, place the cursor at the beginning or end of the reference and use the same shortcuts.
- 除了“model.tmdl”文件外，**从文件打开模型** 对话框现在也会显示“database.tmdl”文件。 It doesn't matter which file is opened - Tabular Editor loads the full model metadata from both files in any case.
- 为 Direct Lake 模型收集 VertiPaq分析器统计信息时，默认只查询驻留列。 This considerable reduces the time it takes to collect statistics for large models. You can still choose to include non-resident columns by changing the **Statistics for Direct Lake models** setting under **Tools > Preferences > VertiPaq Analyzer**.
- 在 **工具 > 偏好 > TOM Explorer > 本地化** 下新增偏好选项，用于控制货币格式：此前货币格式被硬编码为在格式字符串开头使用美元符号（$）。 Now, you can select either a standard formatting style from a searchable dropdown, or define your own custom symbol and positioning.

## 3.15.0 问题修复

- 修复了为“Editor.Dax.FormatLong”和“Editor.Dax.FormatShort”自定义的键盘快捷键无法生效的问题。
- 修复了一个问题：除非 MacroActions.json 文件中的宏定义按宏 ID 排序，否则宏不会被完整加载。详见 [#1151](https://github.com/TabularEditor/TabularEditor3/issues/1151)。
- 如果在“导入表向导”中某个表格预览失败，现在也可以继续预览其他表。
- “导入表向导”中的表格预览现在可以在 Fabric Lakehouse SQL 端点上正常工作。
- 将模型保存为 TMDL 时，默认编码现为不带字节顺序标记（BOM）的 UTF-8，应与 Power BI Desktop 兼容。
- 修复了 **新增功能** 页面上的 URL 工具提示会一直停留在屏幕上的问题。
- 内置的 DAX 格式化器不再将 KPI 引用替换为其基础度量值的引用。
- 修复了“忽略增量刷新分区”和“忽略 Lineage tag”这两项序列化设置未能正确保存的问题。

\*=Direct Lake 模型需要 Fabric Workspace。 As such, they are only accessible for Tabular Editor 3 Enterprise Edition customers.

## 从 Tabular Editor 2.x 升级过来？

看看 [此视频](https://www.youtube.com/watch?v=pt3DdcjfImY)，了解一下 Tabular Editor 3 的新功能。 Also, make sure to check our [onboarding guide](https://docs.tabulareditor.com/onboarding/index.html).

**Tabular Editor 3 主要功能概览：**

- 完全可定制的 IDE，支持多显示器、Hi-DPI 和主题
- 全新强大的 DAX 代码编辑器，提供自动完成、语法检查、代码折叠等丰富功能
- 工作区模式：可将更改保存到磁盘，同时将模型元数据同步到 Analysis Services
- 支持无限滚动的表数据预览；创建 PivotGrid，或编写 DAX 查询来浏览模型并测试计算逻辑
- 计划数据刷新
- 更新 Provider 和 Structured数据源的表架构（没错，连 M 查询也支持！）
- 创建 Data model 示意图
- 创建 DAX 脚本，可在单个文档中编辑多个度量值或其他计算对象
- 录制 C# Script 并将其保存为宏（以前称为“自定义操作”）
- VertiPaq分析器集成
- DAX调试器
