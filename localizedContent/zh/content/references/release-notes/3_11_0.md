### 先决条件

Tabular Editor 3.3.0 (and newer) uses .NET 6. 在启动 Tabular Editor 3.3.0（或更高版本）之前，你可能需要先安装[适用于桌面的.NET 6.0 运行时](https://dotnet.microsoft.com/en-us/download/dotnet/6.0/runtime)。 Starting from 3.3.1, the Tabular Editor 3 installer will download and install these prerequisites, if they are missing.

## 3.11.0 新增功能

查看我们的[发布博客](https://blog.tabulareditor.com/2023/09/25/september-release-tabular-editor-3-11-0/)，快速了解此版本最重要的更新内容。

- 正如我们在[上个月的发布说明](xref:release-3-10-1)中提到的，此前 Tabular Editor 无法从零开始创建 [Direct Lake Dataset](https://learn.microsoft.com/en-us/power-bi/enterprise/directlake-overview)。 This is now possible! The only prerequisite is that the model does not already have any tables or explicit data sources defined, and that its Compatibility Mode is set to PowerBI. Check out our [blog post on DirectLake, if you want to learn more](https://blog.tabulareditor.com/2023/08/23/fabric-direct-lake-dataset/).

> [!WARNING]
> 一旦你通过 XMLA endpoint 对 Direct Lake Dataset 进行任何更改，你将[无法再在 Fabric 的 Web 建模功能中打开该 Dataset](https://learn.microsoft.com/en-us/power-bi/enterprise/directlake-overview#enable-xmla-read-write:~:text=Direct%20Lake%20datasets%20created%20or%20modified%20by%20using%20XMLA%2Dbased%20tools%20cannot%20be%20opened%20in%20the%20Web%20modelling%20feature.)。

## 3.11.0 改进内容

- 我们现已使用最新版本的 [AMO/TOM](https://www.nuget.org/packages/Microsoft.AnalysisServices.NetCore.retail.amd64/) 和 [TMDL](https://www.nuget.org/packages/Microsoft.AnalysisServices.Tabular.Tmdl.NetCore.retail.amd64)，其中包含多项缺陷修复和稳定性改进。

> [!NOTE]
> TMDL 仍处于预览阶段，因此该功能在 Tabular Editor 3 中也属于预览功能。 Make sure to keep a Model.bim / Database.json backup of your model metadata to avoid losing work.

- 我们的 DAX 解析器和自动补全现已支持 [`MINX`](https://dax.guide/minx)/[`MAXX`](https://dax.guide/maxx) 新增的第三个参数。 Moreover, we now also provide suggestions for the [`MATCHBY`](https://dax.guide/matchby) function, which can be used as an optional parameter of window functions.
- 从 Databricks 导入时，只要指定了目录 catalog，“表导入向导”的“原生查询”选项就可用。

## 3.11.0 问题修复

- 使用 `$system.discover_keywords` DMV 更新了 DAX 中的保留表名列表。 The consequence is that our built-in DAX formatter now correctly applies quotes on certain table names, which are also reserved words. For example, a reference to a table named `status` will now always be quoted. See [#991](https://github.com/TabularEditor/TabularEditor3/issues/991).
- 自动补全现在会为诸如 [`RANK`](https://dax.guide) 等 DAX 窗口函数的 _&lt;Skip&gt;_ 参数建议正确的关键字。
- 批量重命名现已支持文件夹，详见 [#797](https://github.com/TabularEditor/TabularEditor3/issues/797)。
- 修复了与自定义布局相关的一些问题，参见 [#711](https://github.com/TabularEditor/TabularEditor3/issues/711)。 Also fixed an issue where customizations to the built-in menus, were not properly persisted.
- 修复了 Deployment Wizard 中的一个问题：当模型包含一个没有分区的增量刷新表时会出错。 In this case, the deployment wizard UI did not allow the user to skip partition deployment of this table which would cause an invalid TMSL to be generated (one with no partitions for the table in question).
- 修复了一个问题：运行 DAX 查询时，如果 [`EVALUATE`](https://dax.guide) 与后续表达式之间没有空白字符，会导致错误。
- Fixed numerous issues with the DAX debugger. 参见 [#954](https://github.com/TabularEditor/TabularEditor3/issues/954)、[#971](https://github.com/TabularEditor/TabularEditor3/issues/971) 和 [#984](https://github.com/TabularEditor/TabularEditor3/issues/984)。

## 正在从 Tabular Editor 2.x 迁移？

观看[此视频](https://www.youtube.com/watch?v=pt3DdcjfImY)，快速了解 Tabular Editor 3 的新功能。 Also, make sure to check our [onboarding guide](https://docs.tabulareditor.com/getting-started/index.html).

**Tabular Editor 3 主要功能概述：**

- 完全可自定义的 IDE，支持多显示器、Hi-DPI 以及主题
- 全新强大的 DAX 代码编辑器，提供自动补全、语法检查、代码折叠等更多功能
- \*工作区模式：可将更改保存到磁盘，并同时将模型元数据同步到 Analysis Services
- \*可无限滚动预览表数据，创建 PivotGrid 或编写 DAX 查询，以浏览模型或测试计算逻辑
- \*计划数据刷新任务
- 在 Provider 数据源和 Structured数据源上更新表架构（是的，甚至包括 M 查询！）
- 创建 Data model 图表
- 创建 DAX脚本，让你在一个文档中编辑多个度量值或其他计算对象
- 录制 C# Script 并将其保存为宏（以前称为“Custom Actions”）
- VertiPaq分析器集成
- DAX调试器

\*=仅在连接到 Analysis Services 或 Power BI 实例时适用
