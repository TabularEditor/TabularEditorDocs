## 从 Tabular Editor 2.x 升级过来？

观看[这个视频](https://www.youtube.com/watch?v=pt3DdcjfImY)，快速了解 Tabular Editor 3 的新功能。

**Tabular Editor 3 主要功能概览：**

- 完全可自定义的 IDE，支持多显示器、Hi-DPI 以及主题
- 全新的强大 DAX 代码编辑器，支持自动完成、语法检查、代码折叠等更多功能
- \*工作区模式，可将更改保存到磁盘，并同时将模型元数据同步到 Analysis Services
- \*支持无限滚动预览表数据，创建 PivotGrids，或编写 DAX 查询来浏览模型或验证计算逻辑
- \*可同时更新 Provider 与 Structured数据源的表架构（没错，连 M 查询也支持！）
- \*安排数据刷新
- 创建 Data model 图
- 创建 DAX 脚本，让你在一个文档中编辑多个度量值或其他计算对象
- 录制 C# Script 并保存为宏（以前称为“Custom Actions”）
- 集成 VertiPaq分析器

\*=仅在连接到 Analysis Services 或 Power BI 实例时可用

## 已知问题

- Table Import Wizard didn't make it to this release. It will be available in 3.0.3 which is coming out very soon. As a work around, simply create a new table and specify the partition query (SQL or M). Then, right-click the table and choose "Update Table Schema..." to import columns.
- 想了解更多信息，可以看看[路线图](https://github.com/TabularEditor/TabularEditor3/issues/12)。

## 3.0.1 中的新功能：

（下方列表对比了 Tabular Editor 3.0.1 与上一版 Beta 版）

- 更新了 [EULA](https://tabulareditor.com/tabular-editor-software-license-agreement_ver-1-0/)，并将 [ThirdPartyNotices.txt](https://github.com/TabularEditor/TabularEditor3/blob/master/ThirdPartyNotices.txt) 添加到安装程序中。
- Schema Compare 现也适用于 Provider（旧版）数据源和查询分区
- 首次使用“Format DAX”按钮时，Tabular Editor 会询问您是否同意将 DAX 代码发送至 www.daxformatter.com Web 服务（Tabular Editor 3 的后续版本将支持离线 DAX 代码格式化，因此届时无需再征得同意）。
- 改进了激活向导中的部分文本，并在当前许可证过期时允许输入新的许可证密钥。
- 在属性网格中新增连接字符串编辑器
- 在“工具 > 偏好 > 架构比较”中新增选项，可全局忽略某些类型的架构差异。
