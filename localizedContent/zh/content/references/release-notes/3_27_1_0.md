## 3.27.1.0 中的改进

- [AI 助手](https://docs.tabulareditor.com/en/features/ai-assistant.html)和通过 [MCP 服务器](https://docs.tabulareditor.com/en/features/mcp-server.html)连接的代理现在可以接收模型和已打开文档中的 DAX 错误：
  - 现在，它会列出“消息”视图中显示的错误、警告和 Analysis Services 消息
  - 活动文档（DAX 查询、DAX 脚本、C# 脚本或 Pivot Grid）的错误和警告将添加到助手的上下文中
  - C# 脚本运行后，结果会列出脚本引入或解决的错误

  Analysis Services 返回的错误文本可能包含模型数据，并且仅当**模型数据**权限设置为**读取**时才会共享。

- 当您打开其他模型时，**DAX 查询**和**Pivot Grid** 文档现在将保持打开状态，并且它们会连接到新模型。DAX 查询会保留其文本和未保存的更改。Pivot Grid 保持其布局，并删除新模型中不存在的字段。要禁用此功能，请在**工具 > 首选项 > 数据浏览**下禁用**打开其他模型时保持 DAX 查询打开**和**打开其他模型时保持 Pivot Grid 打开**。请参阅[DAX 查询：切换模型](https://docs.tabulareditor.com/en/features/dax-query.html#switching-models)和[Pivot Grid：切换模型](https://docs.tabulareditor.com/en/features/pivot-grid.html#switching-models)。
- **模型 > 部署…** 有一个新的**部署语言元数据（问答同义词、AI 指令和 AI 数据架构）**选项，默认选中。取消选中此选项，以保留已在目标语义模型中设置的 AI 指令、AI 数据架构和问答同义词。请参阅[部署选项](https://docs.tabulareditor.com/en/features/deployment.html#deployment-options)。
- 在**文件 > 打开 > 从数据库打开模型...**的**服务器**列表中或部署向导中右键单击服务器，以**固定**、**取消固定**或**删除**该服务器。已固定的服务器位于列表顶部，不会被**清除最近的服务器**移除。请参阅[最近使用的服务器和已固定的服务器](https://docs.tabulareditor.com/en/how-tos/xmla-as-connectivity.html#recent-and-pinned-servers)。
- 窗口标题现在以模型名称开头。**工具 > 首选项 > Tabular Editor > 用户界面**下的**模型源详细信息**首选项取代了**隐藏模型源详细信息**，并设置了标题栏、状态栏、选项卡工具提示和最近列表显示模型位置的多少。状态栏将连接显示为“`<database>@<server>`”。请参阅[用户界面首选项](https://docs.tabulareditor.com/en/references/preferences.html#tabular-editor--user-interface)和[Tabular Editor 3 用户界面](https://docs.tabulareditor.com/en/features/views/user-interface.html#basic-user-interface-elements)。
- **“消息”**视图中有一个**“原因”**列，显示导致级联错误的对象，以及在导致其他对象出错的对象上显示的**“+N 个依赖错误”**。右键单击错误，以清除**显示级联错误**或选择**转到根本原因**。请参阅[级联错误和根本原因](https://docs.tabulareditor.com/en/features/views/messages-view.html#cascading-errors-and-root-causes)。

## 3.27.1.0 中的错误修复

- 修复了将计算项的**序号**设置为将其向其计算组的末尾移动时，将其放置的位置提前了一个位置的问题。
- 修复了**文件 > 新建 > 模型…**仅将所选名称应用于模型，而将数据库命名为`SemanticModel`的问题。
- 修复了对于模型的 **Culture** 属性和翻译的 **Language** 属性接受无效区域设置名称的问题。现在，这些值将被拒绝，并显示错误，例如`'en US' is an invalid culture specifier`。
- 修复了当两个模型在角色成员、查询组或其他未命名集合元素上存在差异时，比较这两个模型失败并显示`Object reference not set to an instance of an object`的问题。
- 修复了 DAX 表达式中的非标准空白字符（例如不间断空格）未被报告的问题。现在，它被报告为一个错误，该错误指明了字符的名称，并提示您运行**格式化 DAX**。
- 修复了**元数据翻译编辑器**中的问题：
  - 清除翻译单元格无效；现在将移除翻译
  - 表格、层次结构级别、透视或模型的**显示文件夹**单元格可编辑，且值被丢弃；这些单元格现在为只读
  - 列标题上下文菜单提供了**显示自动筛选行**，但该功能在翻译列上不起作用
- 修复了在**导入表格向导**列出表格时将其关闭，可能会显示错误报告对话框或导致树中缺少对象的问题。
- 修复了取消**从数据库加载语义模型**对话框或数据源凭据提示可能会关闭 Tabular Editor 并丢失未保存工作的问题。
- 修复了在 **Pivot Grid** 值上使用“**调试此值**”时，忽略或颠倒网格的某些筛选器，导致调试器显示的值与网格中的值不同的问题。
- 修复了以下问题：当 Tabular Editor 不是活动窗口时，MCP 客户端打开的文档显示的是上一个文档的工具栏和菜单。在[GitHub 讨论 #1590](https://github.com/TabularEditor/TabularEditor3/discussions/1590)中报告。
- 修复了以下问题：复制或粘贴显示在多个显示文件夹中的度量值、列或层次结构时，会将副本放入一个以所有文件夹命名的文件夹中，例如`folder_01;folder_02`。现在，副本会出现在原始项的每个显示文件夹中。
- 修复了 **DAX 查询**编辑器中的问题，该问题表现为：在文档中运行多个查询中的一个查询时，使用了第一个查询的 `DEFINE` 块，并且在 `ORDER BY` 子句中执行所选列时失败，并显示`A single value for column ... cannot be determined`。
- 修复了**消息**视图停止列出在打开其他模型后仍保持打开状态的文档的错误的问题。
- 修复了可能导致 Tabular Editor 3 意外关闭或显示错误对话框的问题：
  - 当**属性**视图显示度量值时，或当其所选对象被删除时
  - 打开语义模型时，出现“无法访问已释放的对象”错误
  - 在编辑操作（该操作删除了包含 DAX 表达式的对象并重命名或添加了另一个对象）之后
  - 编辑 DAX 表达式时，出现“索引超出了数组的边界”错误
- 修复了以下问题：使用特定版本 OLE DB 提供程序名称（例如 `Provider=MSOLEDBSQL19.1`）的旧版数据源被报告为未安装，并且 **数据链接属性** 对话框在没有原始提供程序的情况下打开。此问题是自 3.25.0 以来的回归。
- 修复了当无法扫描模型的数据时，**VertiPaq分析器 > 收集统计信息**未返回任何统计信息的问题。现在，统计信息将从模型元数据中收集，并附带警告；清除**工具 > 首选项 > 文件格式 > VertiPaq Analyzer**下的**从数据读取统计信息**将跳过数据读取。

## 来自 Tabular Editor 2.x？

如需了解 Tabular Editor 3 的主要功能，请观看[此视频](https://youtu.be/O4ATwdzCvWc)。要开始使用，请参阅[入门指南](https://docs.tabulareditor.com/onboarding/index.html)。

**Tabular Editor 3 的主要功能：**
- 可定制的 IDE，支持多显示器和高 DPI，并提供主题
- 具备自动完成、语法检查、代码折叠和格式化功能的 DAX 代码编辑器
- *工作区模式，可将您的更改保存到磁盘，并同时将模型元数据同步到 Analysis Services
- *使用无限滚动预览表格数据，创建 PivotGrid 或编写 DAX 查询以浏览模型或测试计算逻辑
- *安排数据刷新
- 更新提供程序和 Structured 数据源（包括 M 查询）上的表格架构
- 创建数据模型图
- 创建 DAX 脚本，以便在单个文档中编辑多个度量值或其他计算对象
- 录制 C# 脚本并将其保存为宏（原“自定义操作”）
- VertiPaq Analyzer 集成
- DAX 调试器
- DAX 优化器集成
- 用于重构您的 DAX 的代码操作

*=仅在连接到 Analysis Services 或 Power BI 实例时
