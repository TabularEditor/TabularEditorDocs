## 重要！

**NOTE**: Tabular Editor 3.3.0 (and newer) uses .NET 6. 在启动 Tabular Editor 3.3.0（或更高版本）之前，你可能需要先安装 [适用于桌面的.NET 6.0 运行时](https://dotnet.microsoft.com/en-us/download/dotnet/6.0/runtime)。 Starting from 3.3.1, the Tabular Editor 3 installer will download and install these prerequisites, if they are missing.

## 3.4.0 中的新功能

- 将 TOM 更新到 [19.54.1](https://www.nuget.org/packages/Microsoft.AnalysisServices.NetCore.retail.amd64)。
- Tabular Editor 3 现已支持在 Power BI Desktop 2022 年十二月更新中宣布的 [新 DAX 窗口函数](https://pbidax.wordpress.com/2022/12/15/introducing-dax-window-functions-part-1/)。
- Customizable keyboard shortcuts are here! Do you want to always use CTRL+S to save the model, regardless of context? Do you want to assign a hotkey to perform a model refresh? How about an editor shortcut to [select all occurrences of current selection](https://github.com/TabularEditor/TabularEditor3/issues/630)? Find this feature under **Tools > Preferences > Keyboard**. More info [here](xref:preferences#tabular-editor--keyboard).
- 所有代码编辑器现在除支持矩形选择（拖动时按住 ALT，或使用 SHIFT + 方向键）外，还支持多重选择（即按住 CTRL 并用鼠标拖动，以创建新的选区）。

## 3.4.0 中的小幅改进

- Tabular Editor 3 现在会在 Power BI“外部工具”功能区中显示正确的图标。
- Consolidated editing of Column-type properties in the property grid. You can now specify a column by typing its name in the property grid. When more than 7 columns are present, a "select column" dialog appears instead of a dropdown. This also fixes [#738](https://github.com/TabularEditor/TabularEditor3/issues/738).
- 在“表格预览”中移除了列名中的方括号
- 现在可以在导入表向导中连接并选择其他 Power BI Workspace。
- Pivot Grid 字段列表现在可以作为可停靠窗口使用，参见 [#742](https://github.com/TabularEditor/TabularEditor3/issues/742)。
- 当源描述中包含 HTML 标记时，DAX 调用提示现在也能正确排版。
- 现在，所有代码编辑器在使用键盘进行选择时，矩形选区功能都有了大幅改进。 Moreover, copy/paste now works more intuitively with rectangular selections.
- 在“工具 > 自定义”对话框（位于“Options”选项卡下）中新增了锁定菜单和工具栏的选项，以防止误将其拖动。
- Scintilla 的多重选择“添加下一个/逐个添加”现在会遵循“查找”对话框中设置的搜索选项。
- 允许 File.SaveModel 快捷键在任何上下文下都能生效，参见 [#762](https://github.com/TabularEditor/TabularEditor3/issues/762)。
- It is now possible to cancel a long-running save operation, such as when the database is locked by a refresh operation. See [#730](https://github.com/TabularEditor/TabularEditor3/issues/730).
- 创建/编辑关系对话框现在支持调整大小，参见 [#732](https://github.com/TabularEditor/TabularEditor3/issues/732)。
- 允许在所有树形列表上用方向键展开/折叠（包括 BPA、依赖关系视图和数据刷新视图），参见 [#775](https://github.com/TabularEditor/TabularEditor3/issues/775)。
- We've listened to your feedback! “显示表的关系”已回归到依赖关系视图，参见 [#731](https://github.com/TabularEditor/TabularEditor3/issues/731)。

## 3.4.0 Bug 修复

- AAD 连接对话框现在在所有情况下都会以模态对话框显示。
- 批量编辑多个对象时，会创建撤销事务
- 现在可以通过右键点击并选择“重置”来清除对象属性（例如 SortByColumn）。
- 新增右键快捷方式，用于编辑表表达式属性（SourceExpression、PollingExpression 等） are now available, see [#721](https://github.com/TabularEditor/TabularEditor3/issues/721).
- 将字段拖到 Pivot Grid 上时，Pivot Grid 不再冻结，参见 [#676](https://github.com/TabularEditor/TabularEditor3/issues/676)。
- 修复问题 [#723](https://github.com/TabularEditor/TabularEditor3/issues/723)。
- 修复了在从 .tmuo 文件中指定的现有 Power BI Dataflow 导入时，会导致表架构无法更新并使“导入表向导”崩溃的问题。
- 修复了 DAX调试器生成的观察表达式 DAX 查询无效的问题，参见 [#770](https://github.com/TabularEditor/TabularEditor3/issues/770)。
- 修复了一个问题：该问题有时会导致调试器窗口崩溃（白色背景上显示红色叉号）。
- 修复了一个问题：“导入表向导”有时会显示名称为空的 Dataflow。
- "Revert" button should always be enabled now. Moreover, a confirmation prompt is only shown when changes have been made. 参见 [#729](https://github.com/TabularEditor/TabularEditor3/issues/729)。
- 显示字段列表不再清空 Pivot Grid，参见 [#741](https://github.com/TabularEditor/TabularEditor3/issues/741)。
- 修复了一个问题：应用启动时，TOM Explorer 中的列有时会被“截断”。
- TOM Explorer 现仅允许在 Power BI 数据集中添加 EntityPartitions
- 修复依赖项视图崩溃问题，参见 [#758](https://github.com/TabularEditor/TabularEditor3/issues/758)
- 修复了一个问题：应用程序重启后，浮动窗口可能会出现在可见屏幕区域之外。参见 [#652](https://github.com/TabularEditor/TabularEditor3/issues/652)。
- 修复“最近使用的服务器”未保存的问题。
- Fixed a few bugs related to how actions appear in the "Model" and/or "Context" menu. 例如，“模型”菜单中的“Script DAX”只会为当前选择中的对象生成脚本，而按设计应为模型中的所有对象生成脚本。
- 修复文本编辑器横向滚动条的行为。
- SQL 连接对话框现在会将对连接字符串所做的更改保存下来，参见 [#755](https://github.com/TabularEditor/TabularEditor3/issues/755)。
- Selecting a database after filtering the list in the "Choose database" dialog, now ensures that the correct database is actually loaded. See [#761](https://github.com/TabularEditor/TabularEditor3/issues/761).
- 修复在表格中滚动时的问题 (参见 [#733](https://github.com/TabularEditor/TabularEditor3/issues/733)，以及应用筛选条件时行数不更新的问题。

## 从 Tabular Editor 2.x 升级过来？

观看[此视频](https://www.youtube.com/watch?v=pt3DdcjfImY)，了解 Tabular Editor 3 的新功能。 Also, make sure to check our [onboarding guide](https://docs.tabulareditor.com/onboarding/index.html).

**Tabular Editor 3 主要功能概览：**

- 完全可自定义的 IDE，支持多显示器、高 DPI 和主题
- 全新强大的 DAX 代码编辑器，具备自动补全、语法检查、代码折叠等众多功能
- \*Workspace 工作区模式：在将更改保存到磁盘的同时，将模型元数据同步到 Analysis Services
- \*支持无限滚动预览表格数据，可创建 PivotGrids 或编写 DAX 查询来浏览模型或测试计算逻辑
- \*支持计划数据刷新
- 在 Provider 数据源和 Structured数据源上更新表架构（没错，连 M 查询也支持！）
- 创建 Data model 关系图
- 创建 DAX 脚本，在单个文档中编辑多个度量值或其他计算对象
- 录制 C# Script 并保存为宏（此前称为“Custom Actions”）
- 集成 VertiPaq分析器
- \*DAX调试器

\*=仅在连接到 Analysis Services 或 Power BI 的实例时
