## 已知问题

- 由于需要修复一些高优先级漏洞，表导入向导未包含在此版本中。它将尽快提供！作为一种变通方法，只需创建一个新表并指定分区查询（SQL 或 M）。然后，右键单击该表并选择“更新表架构……”，以导入列。
- 有关详细信息，请参阅[路线图](https://github.com/TabularEditor/TabularEditor3/issues/12)。

## 3.0.3 中的新功能：

- 现在，右键单击“处理视图”中的项目，即可将该项目重新排入队列，或者，如果该项目代表单个表，则可打开该表的数据预览。

## 3.0.3 中的错误修复：

- 当语义分析器在计算列/计算表格上检测到错误时，它不再修改该表格上的列（这在以前会导致在某些情况下关系被删除）
- 修复了“查找/替换”对话框上某些控件的启用状态问题
- 根据遥测和错误报告修复了多处漏洞，例如：
  - 复制/粘贴带有 Lineage tag 的列现在可以正常工作
  - 在表重命名时将表粘贴到现有表上不再导致崩溃
  - “还原”按钮现在会在刷新本地 TOM 之前重新连接到 AS，而不会导致崩溃
  - 在属性网格为空时右键单击不再导致崩溃
  - 还有很多很多……
- 修复了“服务器”下拉菜单的 MRU 未正确保存的问题
- 修复了工作区模式无法从用户选项文件正确加载数据源覆盖值的多个问题。请参阅 [#28](https://github.com/TabularEditor/TabularEditor3/issues/28)。
- 修复并改进了几个“虚假”DAX 语义错误（支持 ROLLUPADDISSUBTOTAL、COUNTROWS（0 个参数）等）
- 改进了多个 DAX 函数（TOPN、TOPNPERLEVEL、DATEADD/DATESINPERIOD/PARALLELPERIOD 的间隔参数）、RETURN 关键字后的自动补全/参数信息等。

## 来自 Tabular Editor 2.x？

观看[此视频](https://www.youtube.com/watch?v=pt3DdcjfImY)，了解 Tabular Editor 3 的新功能。

**Tabular Editor 3 主要功能概览：**
- 完全可自定义的 IDE，支持多显示器、高 DPI 和主题
- 全新的强大 DAX 代码编辑器，具备自动完成、语法检查、代码折叠等众多功能
- *工作区模式，允许您将更改保存到磁盘，并同时将模型元数据同步到 Analysis Services
- *使用无限滚动预览表格数据，创建数据透视网格或编写 DAX 查询以浏览模型或测试计算逻辑
- *在提供程序和结构化数据源上更新表格架构（是的，即使对于 M 查询也是如此！）
- *安排数据刷新
- 创建数据模型图
- 创建 DAX 脚本，让您能够在单个文档中编辑多个度量值或其他计算对象
- 录制 C# 脚本并另存为宏（以前称为“自定义操作”）
- VertiPaq分析器集成

*=仅在连接到 Analysis Services 或 Power BI 实例时
