## 已知问题

- Table Import Wizard didn't make it to this release due to some high-priority bugs that had to be fixed. It will be available ASAP! As a work around, simply create a new table and specify the partition query (SQL or M). Then, right-click the table and choose "Update Table Schema..." to import columns.
- 更多信息见[路线图](https://github.com/TabularEditor/TabularEditor3/issues/12)。

## 3.0.5 中的改进：

- 图表视图现在看起来好多了（浅色和深色主题均适用），并且在画布上拖动表时，关系连线会实时更新。

## 3.0.5 中的错误修复：

- Expression Editor, if hidden, doesn't automatically pop up when selecting a diagram item / TOM explorer item. 改为在 TOM Explorer 中双击该项，或通过“视图”菜单将其重新显示 (详见问题 [#43](https://github.com/TabularEditor/TabularEditor3/issues/43)。
- DAX 解析器在实际上不存在循环依赖时，将不再报告循环依赖(详见问题 [#63](https://github.com/TabularEditor/TabularEditor3/issues/63) 和 [#64](https://github.com/TabularEditor/TabularEditor3/issues/64))
- 修复了 DAX 解析器在计算表列（CalculatedTableColumns）上确定 SourceColumn 值时的问题；该问题可能导致在加载模型时删除列，进而删除关系。
- DAX parser now shows an error if certain keywords are used as DAX variables (which is not allowed). See issue [#58](https://github.com/TabularEditor/TabularEditor3/issues/58).
- 在开始搜索时按下“:”，现在会立即切换到“整个模型”和 Dynamic LINQ 模式。
- Dynamic LINQ 现在也会搜索分区和计算组项，详见问题 [#70](https://github.com/TabularEditor/TabularEditor3/issues/70)。

## 从 Tabular Editor 2.x 迁移过来？

观看[此视频](https://www.youtube.com/watch?v=pt3DdcjfImY)，快速了解 Tabular Editor 3 的新增功能。

**Tabular Editor 3 主要功能概览：**

- 可完全自定义的 IDE，支持多显示器、Hi-DPI 和主题
- 全新且强大的 DAX 代码编辑器，支持自动补全、语法检查、代码折叠等更多功能
- \*工作区模式：可让你将更改保存到磁盘，同时将模型元数据同步到 Analysis Services
- \*通过无限滚动预览表数据，创建 PivotGrid，或编写 DAX 查询来浏览模型或测试计算逻辑
- \*更新 Provider 数据源和 Structured数据源上的表架构（是的，连 M 查询也支持！）
- \*安排数据刷新计划
- 创建 Data model 示意图
- 创建 DAX 脚本，让你在一个文档中批量编辑多个度量值或其他计算对象
- 录制 C# Script 并保存为宏（以前称为“自定义操作”）
- 集成 VertiPaq分析器

\*=仅在连接到 Analysis Services 或 Power BI 实例时可用
