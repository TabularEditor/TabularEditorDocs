## 3.18.0 新增功能

请查看我们的[发布博客](https://blog.tabulareditor.com/2024/10/31/tabular-editor-3-october-2024-release)，快速了解本次发布中最重要的更新。

- 我们的 **DAX优化器集成** 已结束预览阶段。我们还进行了一些更新，使其支持 [DAX优化器 1.2 中新增的评估指标](https://www.tabulartools.com/blog/introducing-new-evaluation-metrics-in-dax-optimizer-1-2/)。 Oh, and by the way - all **Enterprise Edition** Tabular Editor 3 users now get 4 free DAX Optimizer runs per day. Download Tabular Editor 3.18.0 from one of the links above, and get your DAX Optimizer redemption code through the **Help > About Tabular Editor** menu item.
- 我们很高兴在 Tabular Editor 3 的所有 DAX 编辑器中推出一项新功能：**Code Actions**。 This productivity feature discretely provides suggestions for improving your DAX code and lets you apply the suggestion with a single click. For example, the feature can be used to remove unused variables, follow best practices for column and measure references, rewrite table filters as [more efficient column filters](https://www.sqlbi.com/articles/filter-columns-not-tables-in-dax/), and [much, much more](xref:code-actions). We plan to add additional actions in future releases, so stay tuned!
- 在我们升级到 [最新版本的 Microsoft AMO/TOM 客户端库](https://www.nuget.org/packages/Microsoft.AnalysisServices/) 之后，**集成** 身份验证选项的行为发生了变化：如果 Windows 操作系统已连接到某个 Entra ID 帐户，将不再显示 Entra ID 帐户选择器/MFA 弹窗。 As such, we've added a new authentication option, **Microsoft Entra MFA**, which will force the account selector/MFA popup to appear, letting you choose a different account than the one currently logged in to Windows, if needed.

## 3.18.0 中的改进

- 用户界面偏好设置已扩展，支持在标题栏隐藏模型源的详细信息，帮助你在录屏和演示时保护敏感信息。
- The user interface preferences now include a new "Recent Items" section. This section enables customization of the number of recent files and models displayed in the file menu and the servers displayed in recent connections. The new preferences also allow clearing these items.
- 语义分析器现在会在变量被直接用作 [`CALCULATE`](https://dax.guide/CALCULATE) 或 [`CALCULATETABLE`](https://dax.guide/CALCULATETABLE) 的第一个参数时显示警告。 Since variables are unaffected by context transitions or modified filter contexts, using a variable this way is most likely unintentional.
- 我们的 SQL 编辑器现在采用了改进的配色方案，更容易区分 SQL 关键字与标识符。
- 已将 AMO/TOM 及其他依赖项升级到最新版本。
- We're now using Compatibility Level 1606 for new Power BI / Fabric semantic models. 在该兼容级别下，新增了一个模型属性 [ValueFilterBehavior](https://learn.microsoft.com/en-us/dotnet/api/microsoft.analysisservices.tabular.valuefilterbehaviortype?view=analysisservices-dotnet)，可用于控制 [`SUMMARIZECOLUMNS`](https://dax.guide/SUMMARIZECOLUMNS) 的 _auto-exist_ 行为。
- 我们新增了对 TOM [ChangedProperties](https://learn.microsoft.com/en-us/dotnet/api/microsoft.analysisservices.tabular.changedproperty?view=analysisservices-dotnet) 集合的支持（适用于表、度量值、列以及其他一些对象）。 This collection is used on composite or Direct Lake models, to indicate that a property (such as a column **Name**) has changed, and should no longer be synchronized from the underlying source.
- 已将 VertiPaq分析器升级到最新版本 [(1.7.2)](https://github.com/sql-bi/VertiPaq-Analyzer/releases/tag/v1.7.2)，修复了在对包含 Field Parameters / Group By Columns 的模型提取统计信息时的问题。
- 已将 Snowflake .NET 连接器版本升级到 v. 4.1.0。 This addresses the following vulnerabilities: [CVE-2023-34230](https://nvd.nist.gov/vuln/detail/CVE-2023-34230) and [CVE-2023-51662](https://nvd.nist.gov/vuln/detail/CVE-2023-51662).
- 在处理包含大量关系的大型关系图时，关系图组件的速度现已显著提升。
- 现在你可以在“数据预览”中隐藏列：右键点击列标题，然后选择“隐藏此列”。 To show hidden columns, right-click on a column header and select "Column chooser". This will bring up a window from where you can access previously hidden columns.

## 3.18.0 中的错误修复

- 修复了一个 Bug：在“从数据库加载语义模型”对话框中，“服务器”下拉列表不会显示最近使用过的服务器。
- Data Preview settings (sort order, filters, etc.) 刷新预览后，这些设置现在会被保留，修复了此前设置无法保存的问题。
- 修复了一个可能导致崩溃的问题：在 DAX 编辑器中使用“重命名”重构期间或刚完成后按撤销（Ctrl+Z）时可能发生崩溃。
- 当显示“请稍候”对话框时（例如执行表架构更新时），主界面现在会正确锁定，避免你在此期间进行操作。
- 在 DAX 表达式中引用内部“FormatString”度量值时，语义分析器不再显示警告。因此，现在可以调试包含此类引用的查询（尽管目前仍无法调试 FormatString 表达式本身），请参阅 [#1377](https://github.com/TabularEditor/TabularEditor3/issues/1377)。

## 3.18.0 已知问题

- 如果你在刷新令牌时遇到错误信息 **Can't obtain account information for '(e-mail)' while trying to refresh the token.**，通常重新执行一次操作就能解决。 This is an issue in the newer versions of the AMO/TOM client libraries. You should also be able to avoid this issue by choosing the **Microsoft Entra MFA** authentication option, instead of the **Integrated** option, when initially connecting.

## 正在从 Tabular Editor 2.x 迁移？

观看[这个视频](https://youtu.be/O4ATwdzCvWc)，快速了解 Tabular Editor 3 的主要功能。 Also, make sure to check our [onboarding guide](https://docs.tabulareditor.com/onboarding/index.html).

**Tabular Editor 3 主要功能概述：**

- 完全可自定义的 IDE，支持多显示器、Hi-DPI 以及主题
- 全新强大的 DAX 代码编辑器，提供自动补全、语法检查、代码折叠等更多功能
- \*工作区模式：可将更改保存到磁盘，并同时将模型元数据同步到 Analysis Services
- \*可无限滚动预览表数据，创建 PivotGrid 或编写 DAX 查询，以浏览模型或测试计算逻辑
- \*计划数据刷新任务
- 在 Provider 数据源和 Structured数据源上更新表架构（是的，甚至包括 M 查询！）
- 创建 Data model 图表
- 创建 DAX脚本，让你在一个文档中编辑多个度量值或其他计算对象
- 录制 C# Script 并将其保存为宏（以前称为“Custom Actions”）
- VertiPaq分析器集成
- DAX调试器
- 集成 DAX优化器
- 通过代码操作轻松重构 DAX。

\*=仅在连接到 Analysis Services 或 Power BI 实例时适用
