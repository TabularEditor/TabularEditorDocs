# 使用 Tabular Editor 中的“属性”视图

“属性”视图显示您在 TOM Explorer 中所选对象的属性，并允许您编辑这些属性。在 Tabular Editor 3 中，如果启用了**基本属性视图**公开预览，该视图的底部将有两个选项卡：

- **基本**：一个包含 Power BI Desktop 在其**模型视图**的**属性**窗格中显示的字段的表单，例如度量的名称、描述、显示文件夹和格式。
- **高级**：包含对象的每个属性的属性网格、工具栏和搜索框。它还列出了 Visual Studio 和 Power BI Desktop 不显示的属性。

> [!NOTE]
> **基本**和**高级**选项卡为公开预览版。在您启用预览之前，“属性”视图仅显示 [“高级”选项卡](#advanced-tab)下所述的属性网格，与 Tabular Editor 2 中相同。

## 启用“基本”选项卡

1. 转到**工具 > 首选项 > Tabular Editor > 公共预览**。
2. 勾选**基本属性视图**。
3. 点击**确定**。

“属性”视图显示“基本”和“高级”选项卡。要仅返回属性网格，请取消选中**基本属性视图**。请参阅[公开预览](xref:preferences#tabular-editor--public-previews)。

## 选择选项卡

点击“属性”视图底部的**“基本”**或**“高级”**以切换选项卡。对于每个对象以及在重新启动后，您单击的选项卡都将保持选中状态。**在“高级”中显示**、**显示“高级”**以及跳转到属性会切换到**“高级”**，而不会更改该选择，因此在重新启动后，视图将在您上次点击的选项卡上打开。

当您启用预览时，属性视图将在**基本**选项卡上打开。如果您关闭预览功能，然后再重新打开，它将打开您之前所在的选项卡。要设置选项卡，请在**工具 > 首选项 > Tabular Editor > 公开预览**中的**基本属性视图**下更改**属性视图选项卡**。

## “基本”选项卡

![度量值的“属性”视图的“基本”选项卡](~/content/assets/images/user-interface/properties-view-basic.png)

**基本**选项卡为每个属性显示一个字段，其标签位于字段上方。描述显示为多行文本框，**已隐藏**等选项显示为开关，而选择项显示为列表。列表使用 Power BI Desktop 中使用的名称，例如数据类型的**日期/时间**或列汇总的**不汇总**。**基本**选项卡没有工具栏。

单行字段（例如列表和文本框）在 100% 缩放时宽度约为 250 像素，因此它们会排成一行。当字段显示的值较宽时，字段的宽度与视图的宽度相同；当视图较窄时，字段的宽度会缩小。打开的列表可以比其字段更宽，因此长项目不会使字段变宽。如果文本较短，**“描述”**框将显示一行，并在您键入时扩展为四行。

当鼠标指针位于列表或**描述**框上方时，鼠标滚轮将滚动表单。点击进入**说明**以滚动其文本。

从开放列表中选择的值会立即应用。当焦点位于封闭列表中时，**向上**、**向下**、**Home**、**End** 或字母键可逐个浏览值，但不会应用这些值。按 **Enter** 或离开该字段即可应用该值，或按 **Esc** 再次显示当前值。对于您可以输入内容的列表（例如**数据类别**或**兼容级别**），当您按**Enter**、离开字段或从列表中选择时（而不是在您输入时）才会应用该值。

**显示文件夹**和旧版数据源的**连接字符串**都有一个 **...** 按钮，该按钮将打开与**高级**选项卡上相同的对话框：对于显示文件夹，是**选择文件夹**对话框；对于连接字符串，是连接对话框。

### 每个对象类型的字段

字段取决于所选对象的类型：

| 对象 | 字段 |
|---|---|
| 度量值 | **名称**、**主表**、**描述**、**显示文件夹**、**是否隐藏**、**格式**、**表达式** |
| 列 | **名称**、**描述**、**显示文件夹**、**是否隐藏**、**数据类型**、**格式**、**排序依据列**、**数据类别**、**汇总依据**、**是否可为空**。导入列还具有**源列**，位于**数据**下方。计算列在**数据**之前具有**表达式**。 |
| 表格 | **名称**、**描述**、**是否隐藏**、**键列**、**数据类别**、**存储模式**、**表达式**、**行级安全性**。计算表格在**数据**之前有**表达式**。|
| 计算组 | **名称**、**描述**、**是否隐藏**、**计算项**、**计算组优先级**（存在多个计算组时） 、**表达式** |
| 关系 | **源表**、**源列**、**基数**、**目标表**、**目标列**、**使此关系处于活动状态**、**交叉筛选器方向** |
| 层次结构 | **名称**、**描述**、**显示文件夹**、**是否隐藏**、**级别** |
| 级别 | **名称**、**描述**、**列** |
| 计算项 | **名称**、**描述**、**序号**、**表达式** |
| KPI | **描述**，以及**状态**、**目标**和**趋势**部分，每个部分都有其**表达式**框 |
| 模型 | **名称**、**描述**、**兼容性模式**、**兼容性级别**、**区域性**、**不建议使用隐式度量值** |
| 角色 | **名称**、**描述**、**模型权限**、**行级安全性** |
| 表格权限 | **表格**（只读）、**表达式** |
| 分区 | **名称**、**描述**、**表达式** |
| 共享表达式 | **名称**、**描述**、**表达式** |
| DAX 用户定义函数 | **名称**、**描述**、**是否隐藏**、**表达式** |
| 日历 | **名称**、**描述**、**列映射** |
| 旧版数据源 | **名称**、**描述**、**连接字符串** |
| Power Query 数据源 | **名称**、**描述**、**协议**、已设置的地址字段（例如**服务器**和**数据库**）、**身份验证类型** |
| 透视 | **名称**、**描述**、**在透视编辑器中编辑** |
| 文化 | **语言**、**在元数据翻译编辑器中编辑** |
| 显示文件夹、表组 | **名称** |

重命名显示文件夹会将该文件夹中的对象移至新文件夹，重命名表组会将该组中的表移至新组，作为一个撤消步骤。此操作方式与在 TOM Explorer 中重命名文件夹或组的方式相同。

**主表**将度量值移动到另一个表，方式与在 TOM Explorer 中拖动度量值相同。**键列**设置用于标识表行的列，选择一列将清除之前具有该标记的列的标记。**数据类别**设置表包含的数据类型，例如**时间**。**存储模式**将表的分区模式设置为**导入**、**DirectQuery**或**双重**。对于计算表、Direct Lake 表、推送表和策略范围表，以及分区具有不同模式的表，此字段为只读。

如果模型不允许更改，则字段为只读。例如，当 Tabular Editor 连接到限制外部工具可执行建模操作的 Power BI Desktop 版本时，**主表**、**级别**和**计算项**可能为只读。请参阅[受支持的建模操作](xref:desktop-integration#supported-modeling-operations)。

当所选对象在“基本”选项卡上没有字段（例如角色成员）时，该选项卡将显示“此对象没有基本属性”。**点击**显示高级**，在**高级**选项卡上查看其属性。

### 部分

当表单有多个字段组时，字段位于各部分中，各部分之间有一条分隔线：

- **常规**：对象的名称、描述、显示文件夹、可见性和其他字段。
- **格式化**：**数据类型**和**格式**。
- **数据**：表上的**键列**、**数据类别**和**存储模式**，以及列上的**源列**、**排序依据列**、**数据类别**、**汇总依据**和**可为空**。
- **连接**：数据源的连接字段。请参阅[数据源](#data-sources)。
- **级别**：请参阅[层次结构级别](#hierarchy-levels)。
- **计算项**：请参阅[计算项](#calculation-items)。
- **列映射**：请参阅[日历列映射](#calendar-column-mappings)。
- **计算组优先级**：请参阅[计算组优先级](#calculation-group-precedence)。
- **状态**、**目标**和**趋势**：请参阅[KPI](#kpis)。
- **表达式**：请参阅[表达式](#expressions)。
- **行级安全性**：请参阅[行级安全性](#row-level-security)。

点击章节标题即可折叠该章节，再次点击即可展开。使用键盘时，按 **Tab** 键可移动到标题，按 **空格键** 或 **Enter** 键可折叠标题。对于每个对象以及在重新启动后，折叠的版块将保持折叠状态。字段全部属于**常规**（例如关系或模型）的表单没有章节标题。

**数据**、**级别**、**计算项**、**列映射**、**计算组优先级**、**表达式**和**行级安全性**标题均设有信息按钮。点击该按钮，或在标题上按 **F1**，以阅读该部分的操作说明。对于大多数对象，备注还链接到文档。

### 格式

对于具有数值或日期/时间数据类型的度量值或列，或者数据类型尚不确定的度量值，**“格式”**会列出**“高级”**选项卡提供的格式，然后是**“自定义”**：

- 对于数字：**常规**、**整数**、**小数**、**货币**、**百分比**和**科学计数法**
- 对于日期：**常规**和日期模式

列表下方的文本框始终显示格式字符串。选择数字格式将保留当前格式字符串的小数、千位分隔符和负数样式。要编写您自己的格式字符串，请选择**自定义**或单击文本框，输入格式字符串并按 **Enter** 或离开文本框。按 **Esc** 键可放弃您键入的内容。该列表显示与格式字符串匹配的格式，如果没有格式匹配，则显示**自定义**。

具有文本、真/假或二进制数据类型的列包含用于格式字符串的文本框，但不包含列表。有关**货币**写入的格式字符串，请参阅 @preferences 下的**本地化**设置。

### 关系

关系的端点是**源表**和**源列**，以及**目标表**和**目标列**。当您选择一个表时，其列列表会打开，以便您可以选择该表的一列。当您选择**目标表**时，系统会为您选择与**源列**匹配的列，如**编辑关系**对话框中所示。您选择的列将立即应用。没有列的表不会被应用，如果保留端点，则显示关系的原样。**基数**设置关系的两个端点，例如**多对一 (\*:1)**，而**交叉筛选器方向**提供**单向**、**双向**和**自动**。

更改将像在**编辑关系**对话框中一样被选中，结果将以图标的形式显示在列表旁边：

- 错误未被应用。选择另一端的表是一个错误，因为关系不能将表与自身联接。焦点将一直停留在末端，直到您更正为止，或者按 **Esc** 显示关系的原有状态。
- 应用了警告。属于其他数据类型的列，或在同一两个表之间建立第二个活动关系的列，会收到警告。按 **Ctrl+Z** 撤消更改。

当 Tabular Editor 连接到模型时，只有在您更改列后（而不是在您选择关系时）才会对服务器运行参照完整性检查。在 Direct Lake 模型上，它不会运行。

### 层次结构级别

层次结构的**级别**部分从顶部开始列出其级别，并进行编号。当级别的名称与其列的名称不同时，列将显示在级别的名称之后。编辑列表中的级别：

| 操作 | 鼠标 | 键盘 |
|---|---|---|
| 移动级别 | 将其拖动到另一个位置 | 在所选级别上按 **Alt+向上键** 或 **Alt+向下键** |
| 重命名级别 | 双击其名称 | 在所选级别上按 **F2** |
| 删除一个级别 | 点击该级别所在行的 **x** | 在所选级别上按 **Delete** |

要添加级别，请点击**添加级别**并选择一列。该列表显示了不在层次结构中的表列，您选择的列将成为最底层。每次移动、重命名、移除或添加都是一个撤消步骤。

请参阅@object-properties-hierarchies，了解层次结构和级别的属性。

### 计算项

计算组的**计算项**部分按顺序列出其计算项，并进行编号。移动、重命名和移除项目的方式与层次结构级别相同：拖动项目或按 **Alt+向上键** 或 **Alt+向下键**，双击其名称或按 **F2**，然后单击其 **x** 或按 **Delete**。

单击**添加计算项**，在列表末尾添加项。它将在表达式编辑器中打开，您可以在其中编写其 DAX。每次移动、重命名、删除或添加都是一个撤消步骤。

移动操作会按照新顺序从 0 开始对每个项目的**序号**进行编号，即使序号从 1 开始或存在间隙也是如此。预计每个项目的序号都会在模型文件的差异中显示为已更改。

计算组没有**键列**、**存储模式**或**行级安全性**，因为引擎不会将它们用于计算组。

### 计算组优先级

在包含多个计算组的模型中，计算组的表单中有一个**计算组优先级**部分，其中列出了模型的每个计算组，从**最先应用**到**最后应用**。优先级最高的组位于顶部，所选组以粗体显示，每个组的优先级编号位于右侧。当多个计算组更改同一度量值时，将首先应用列表中排名较高的组。

要更改顺序，请将组拖动到另一个位置，或选择组并按 **Alt+向上键** 或 **Alt+向下键**。移动操作会根据新顺序重新分配各组已有的优先级值，因此未移动的组将保留其优先级值。当两个组共享一个优先级值时，移动操作会改为对每个组进行编号，从最后应用的组的 0 开始。每次移动算作一个撤消步骤。

有关 `Precedence` 属性的信息，请参阅 @object-properties-calculation-groups。

### 日历列映射

日历的**列映射**部分显示一个框，其中包含每个时间单位及其主列的行。具有关联列的单位在其列后显示（例如）**+2 个关联**，而**时间相关**行列出时间相关的列。单击该框，即可在[日历编辑器](xref:calendars)中编辑映射。对于没有映射的日历，该框显示**未映射时间单位。单击以在日历编辑器中映射列。**

请参阅 @object-properties-calendars，了解日历的属性。

### 模型

**兼容级别**列出了模型的当前兼容级别以及 Tabular Editor 针对模型的兼容模式所知的更高级别。对于 Power BI 模型，这是当前级别和 Power BI 支持的最高级别。从列表中选择一个级别，或输入一个级别并按 Enter 键，或离开该框。如果模型中的对象需要的级别高于您输入的级别，则会显示一个错误，指出该对象的名称，并且级别不会发生变化。兼容级别的更改是一步撤消操作。请参阅 @update-compatibility-level。

**兼容模式**为**Analysis Services**或**Power BI**。当您选择其他模式时，**兼容级别**将列出该模式的级别。如果模型无法使用您选择的模式，则会显示错误，且模式不会发生变化。

当模型不允许更改时，**兼容模式**和**兼容级别**为只读。

**区域性**为只读，并列出模型的区域性，其中模型的自有区域性排在首位，例如**en-US (model)、da-DK**。没有区域文化的模型显示 **(无)**。要添加或移除区域性，请使用 TOM Explorer 中的**翻译**节点。区域性的表单具有“在元数据翻译编辑器中编辑”按钮，而透视的表单具有“在透视编辑器中编辑”按钮，这两个按钮可打开所选区域性或透视的编辑器。

### 数据源

旧版数据源显示其**连接字符串**，其中密码被替换为 `********`。编辑连接字符串的其余部分，数据源将保留其密码。点击 **…**，在连接对话框中构建连接字符串。

Power Query 数据源显示其**协议**、其地址中已设置的部分（例如**服务器**和**数据库**）及其**身份验证类型**。您清空的字段将保留在表单上，为空，直到模型保存为止，以便您可以输入新值。要设置地址的另一部分，请使用“高级”选项卡。

### KPI

KPI 包含**状态**、**目标**和**趋势**部分，每个部分都以其**表达式**框开头：

- **状态**：**表达式**、**描述**和**图形**
- **目标**：**表达式**、**描述**和**格式**
- **趋势**：**表达式**、**描述**和**图形**

单击**表达式**框，在表达式编辑器中编写表达式。表达式为空的版块将被折叠。KPI 没有**表达式**部分，也没有**添加表达式**。

### 表达式

**表达式**部分在框中显示对象的 DAX、M 和 SQL 表达式。每个框最多显示其表达式的四行，当表达式更长时，会淡出。框角处的标签标明了语言名称：**DAX**、**M** 或 **SQL**。空框具有虚线边框。点击一个框，或在其获得焦点时按 **Enter** 或 **空格键**，即可在**表达式编辑器**中打开该表达式。光标将移至“表达式编辑器”，因此您可以立即开始输入。

对象的主表达式始终有一个框，例如度量的**表达式**或分区的查询。当框为空时，框中显示的内容例如为**未设置。点击以在表达式编辑器中编写 DAX。**其他表达式（例如**格式字符串表达式**和**详细信息行表达式**）在设置时会显示一个框。

要设置另一个表达式，请单击**添加表达式**。该列表显示尚未设置的表达式，每个表达式都有一行说明其用途。某些条目包含指向解释该条目的页面的链接，例如**详细信息行表达式**，该链接将打开[详细信息行表达式](xref:detail-rows-expression)。选择一个条目以添加空框，然后在表达式编辑器中打开该条目。空框将一直保留，直到您选择另一个对象。

当选择一个对象时，**表达式**部分会显示在除 KPI 之外的每个具有表达式的对象类型上。请参阅[KPI](#kpis)。

### 行级安全性

表和角色具有**行级安全性**部分。在表格上，它为在表格上具有筛选器的每个角色显示一个框。在角色上，它为角色筛选的每个表格显示一个框。点击一个框，在表达式编辑器中打开筛选器。

要添加筛选器，请在表上单击**为角色添加筛选器**，或在角色上单击**在表上添加筛选器**，然后选择角色或表。将添加一个空筛选器，并在表达式编辑器中打开。角色的**模型权限**不会发生变化。**编辑 > 撤消**可一步删除筛选器。

请参阅 @data-security-setup-rls，了解如何编写筛选器。

### 选择多个对象

当您选择多个对象时，**“基本”**选项卡将显示它们共有的字段。表单顶部显示选择了多少个对象，例如**3 个量度**，或者当它们具有不同类型时显示**5 个对象**。值在对象之间不同的字段显示为 **(多个值)**。编辑操作会将每个所选对象上的字段设置为一个撤消步骤，因此 **Ctrl+Z** 会在所有对象上撤消该操作。

这些字段一次仅适用于一个对象，并且在选择多个对象时不会显示：

- **名称**和**键列**
- 级别的**列**和计算项的**序号**
- 关系的**源表**、**源列**、**目标表**和**目标列**
- 表格权限的**表格**
- **级别**、**计算项**、**列映射**和**计算组优先级**
- **表达式**、KPI **表达式**框和**行级安全性**
- **在透视编辑器中编辑**和**在元数据翻译编辑器中编辑**按钮

### “高级”选项卡上的属性

当所选对象在仅“**高级**”选项卡显示的属性中具有值时，表单底部的行会显示值的数量，例如“**3 个高级属性具有值。**如果选择了多个对象，该行将统计具有此类值的对象。翻译、透视成员资格、对象级安全性、自定义注释和选项的计数与其默认计数不同。沿袭标签、同义词、只读属性、Tabular Editor 推断的值以及 Power BI Desktop 和 Tabular Editor 写入的注释均不计入。

点击**在“高级”中显示**，打开**“高级”**选项卡，并启用**仅显示具有值的“高级”属性**，这样网格中仅列出这些属性。要再次查看所有属性，请关闭工具栏上的**仅有值的“高级”属性**，选择其他对象或切换到**“基本”**。

## “高级”选项卡

**“高级”**选项卡是一个属性网格，包含所选对象类型的每个属性，例如名称、描述、数据类型、格式字符串、翻译和注释。有关每个属性的说明，请参阅@object-properties。

</figure>

在**“高级”**选项卡上，您可以：

- 查看和修改模型中任何对象的属性，例如表、列、度量值、层次结构、关系、分区、角色和透视。
- 使用搜索框和视图顶部的按钮，按名称或类别筛选和排序属性。
- 使用 **Ctrl+C** 和 **Ctrl+V** 在不同对象之间复制和粘贴属性值。
- 使用 **Ctrl+Z** 和 **Ctrl+Y** 撤消和重做属性更改。
- 使用键盘导航和编辑属性。例如，按 **Ctrl+向上键** 或 **Ctrl+向下键** 在属性之间移动，按 **Enter** 或 **F2** 编辑属性值，按 **Esc** 取消编辑。

> [!TIP]
> 您可以多选对象，以查看它们具有的共同属性并批量编辑这些属性。例如，这对于设置格式字符串可能很有用。

### 工具栏

**“高级”**选项卡顶部的工具栏包含以下按钮：

- **分类**：将属性分组为*常规*、*元数据*和*选项*等类别。
- **按字母顺序**：在单个按字母顺序排序的列表中列出所有属性。
- **显示更改**：隐藏自上次保存模型以来未更改的所有属性，以便仅保留具有[未保存更改](xref:unsaved-changes)的属性。当筛选器处于活动状态时，视图的标题显示为**属性（已更改）**。
- **仅包含值的“高级”属性**：仅列出包含值且不显示在“基本”选项卡上的属性。该按钮仅在**“基本属性”视图**预览开启时显示。请参阅[“高级”选项卡上的属性](#properties-on-the-advanced-tab)。
- **属性描述**：显示或隐藏视图底部的描述窗格，该窗格对当前选定的属性进行说明。有关每个属性的完整说明，请参阅@object-properties。
- **搜索框**：按名称筛选属性列表。

## 未保存的更改

在**高级**选项卡上，与模型上次保存的版本不同的属性将以浅橙色行背景显示。在**基本**选项卡上，已更改的字段具有相同的着色，并且在其标签后显示更改图标。已更改的表达式框在其名称后显示该图标。**级别**、**计算项目**和**计算组优先级**中已更改的行也会显示该图标。当该部分中的内容发生变化时，**级别**、**计算项目**、**列映射**、**计算组优先级**、**表达式**和**行级安全性**标题也会显示该图标。当选择多个对象时，如果任何所选对象更改了某个属性，则该属性会被标记。

<figure style="padding-top: 15px;">
  <img class="noscale" src="~/content/assets/images/unsaved-changes/revert-property.png" alt="包含未保存更改的属性视图" style="width: 500px;"/>

在**“高级”**选项卡上，右键单击已标记的行，然后选择**“还原”**，将该属性还原为上次保存时的值，而不影响任何其他未保存的更改。还原是撤消堆栈上的单个步骤，因此 **Ctrl+Z** 会将更改恢复。请参阅 @unsaved-changes ，了解详细信息，包括如何从 TOM Explorer 中还原整个对象，以及如何在**“工具”>“首选项”**下关闭指示器。

## 停靠

“属性”视图默认位于右下角，但您也可以按键盘上的 F4 打开它。您还可以将其停靠在主窗口的任何一侧，或将其取消停靠为单独的窗口。
