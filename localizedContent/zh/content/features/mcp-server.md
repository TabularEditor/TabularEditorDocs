# MCP 服务器

Tabular Editor 3 可以充当 MCP（模型上下文协议）服务器。支持 MCP 的代理（例如 Claude Code、GitHub Copilot、VS Code 代理模式、Codex 或 Cursor）连接到正在运行的实例，以读取、查询和分析您已打开的语义模型，并在您授予写入权限的情况下对其进行更改。要开始，请选择**工具 > MCP 服务器…**，然后注册您的代理。

MCP 服务器不使用在 Tabular Editor 中配置的 AI 提供商或 API 密钥，您的代理使用其自己的提供商和订阅。

代理在 Tabular Editor 已打开的模型上工作，包括未保存的更改。这可以是 Power BI Desktop 模型、PBIP 项目、TMDL（表格模型定义语言）文件夹、`.bim`文件、工作区数据库或与 Analysis Services、Azure Analysis Services 或 Fabric 的实时连接。无论模型是已连接还是离线，代理都使用相同的工具，但需要实时连接的工具（例如 DAX 查询）除外。

代理更改会经过 [Tabular Object Model (TOM) 包装器](xref:csharp-scripts)和 C# 脚本引擎，并与您自己的编辑使用相同的验证、公式修复和撤消栈。它们显示为未保存的更改，在[TOM Explorer 和“属性”视图](xref:unsaved-changes)中标记，并且在您保存之前不会将任何内容写入源。

## 开始之前

- Tabular Editor 3.27.0 或更高版本，任何版本。
- 已安装**AI 功能**组件。从 3.27.0 版本起，它是默认安装的一部分。如果您集中部署 Tabular Editor，请参阅@installation-activation-basic；如果您的管理员已禁用 AI 功能，请参阅@policies。
- 支持通过可流式传输的 HTTP 使用 MCP 的代理。

## 启动服务器

1. 选择**工具 > MCP 服务器……**。
2. 查看权限。请参阅[设置代理权限](#set-agent-permissions)。
3. 点击**启动服务器**。

除非您更改了端口，否则该对话框将显示服务器侦听的地址：`http://127.0.0.1:42100/`。状态栏指示器从**MCP 已停止**变为**MCP 已启动**，其工具提示中显示地址。

![MCP 服务器对话框，显示服务器 URL、已屏蔽的访问令牌以及设置为非默认级别的五个代理权限行](~/content/assets/images/features/mcp-server/mcp-server-dialog.png)

![MCP 状态栏指示器显示“MCP 已启动”，其工具提示显示“MCP 服务器正在监听 http://127.0.0.1。点击可打开连接对话框。"](~/content/assets/images/features/mcp-server/status-bar-menu.png)

服务器在打开或未打开模型的情况下均可运行。如果没有打开模型，工具结果会显示这一点，您可以随时打开模型，而无需重启服务器。

右键单击状态栏指示器，即可启动或停止服务器、复制注册配置或打开 MCP 服务器偏好设置。左键单击它，即可打开对话框，而无需启动或停止服务器。

![MCP 状态栏指示器，其右键菜单在“MCP 服务器详细信息…”、“停止 MCP 服务器”、“复制 MCP 配置”和“MCP 服务器首选项…”上打开，并且“复制 MCP 配置”子菜单已展开，列出了 Claude Code、VS Code、Copilot CLI、Codex 和 Cursor](~/content/assets/images/features/mcp-server/status-bar-context-menu.png)

### MCP 偏好

打开**工具 > 首选项 > AI 功能 > MCP 服务器**，设置服务器的启动、身份验证和端口选项。

![MCP服务器首选项，显示“启用MCP服务器”、“自动启动MCP服务器”、“需要访问令牌”和端口](~/content/assets/images/pref-mcp-server.png)

| 首选项 | 默认值 | 功能 |
| -- | -- | -- |
| **启用 MCP 服务器** | 开 | 取消勾选此项将停止正在运行的服务器，并移除菜单项和状态栏指示器 |
| **自动启动 MCP 服务器** | 关闭 | Tabular Editor 启动时启动服务器 |
| **需要访问令牌** | 关闭 | 代理必须出示服务器对话框中显示的访问令牌。请参阅[在共享计算机上运行](#running-on-a-shared-machine) |
| **端口** | 42100 | 服务器侦听的环回端口，范围为 1024 至 49151。更改此端口将使现有代理注册失效 |

## 注册您的代理

在服务器对话框中，从**导出配置**中选择您的代理，然后将复制的配置粘贴到您的代理中。您只需对每个代理注册一次，配置会将服务器注册为`tabular-editor`的名称。

![“导出配置”下拉菜单，展开后列出了Claude Code、VS Code、Copilot CLI、Codex和Cursor](~/content/assets/images/features/mcp-server/export-configuration.png)

**Claude Code**：在终端中运行复制的命令：

```bash
claude mcp add --transport http tabular-editor http://127.0.0.1:42100/
```

**VS Code**：添加到您的 MCP 配置：

```json
{
  "servers": {
    "tabular-editor": {
      "type": "http",
      "url": "http://127.0.0.1:42100/"
    }
  }
}
```

**Copilot CLI**：添加到`~/.copilot/mcp-config.json`：

```json
{
  "mcpServers": {
    "tabular-editor": {
      "type": "http",
      "url": "http://127.0.0.1:42100/"
    }
  }
}
```

**Codex**：添加到`~/.codex/config.toml`：

```toml
[mcp_servers.tabular-editor]
url = "http://127.0.0.1:42100/"
```

**Cursor**：添加到`~/.cursor/mcp.json`：

```json
{
  "mcpServers": {
    "tabular-editor": {
      "url": "http://127.0.0.1:42100/"
    }
  }
}
```

当**需要访问令牌**开启时，导出的配置将以每个客户端的格式包含令牌。从对话框中复制配置；不要手动书写。

任何其他MCP客户端都通过可流式传输的HTTP连接到`http://127.0.0.1:42100/`。如果**需要访问令牌**已启用，请在`Authorization: Bearer <token>`标头中发送令牌。

### 检查是否成功

询问您的代理：

> 我在 Tabular Editor 中连接的是哪个模型？

代理将回答模型名称、模型的加载方式、是否存在未保存的更改及其兼容性级别，或者报告未打开任何模型。Tabular Editor 中不会显示提示。

智能体收到的模型名称遵循 **工具 > 首选项 > Tabular Editor > 用户界面** 下的 **模型源详细信息** 设置。如果选择**仅名称**，则智能体不会收到文件路径或服务器名称；如果选择**隐藏**，则智能体将收到`Model loaded`而非模型名称。

## 设置代理权限

权限控制代理可以获得的工具，[AI 助手](xref:ai-assistant)使用相同的权限。请在**工具 > MCP 服务器……**对话框中或在**工具 > 首选项 > AI 功能 > 权限**下设置权限，两者均可编辑同一设置。

![“AI 功能权限”页面，每个资源都有一个处于默认级别的下拉列表](~/content/assets/images/pref-ai-permissions.png)

将鼠标悬停在权限的标签或下拉菜单上，查看每个级别允许的内容。如果管理员已通过[策略](xref:policies)对资源设置了上限，则下拉菜单为只读，并显示该策略。

每个资源都有一个访问级别：

| 资源 | 默认 | 代理可获得的内容 |
| -- | -- | -- |
| **模型元数据** | 读取 | 读取：表、列、度量、表达式、描述、关系、VertiPaq分析器统计数据以及模型的错误和警告消息。写入：通过 C# 脚本更改模型的能力 |
| **模型数据** | 拒绝 | 读取：DAX 查询结果（来自模型的数据值）以及 Analysis Services 返回的错误文本，其中可能包含数据值。DAX 查询需要实时连接 |
| **最佳实践分析器** | 读取 | 读取：规则集和分析结果。写：添加和修改规则 |
| **文档** | 写入 | 读取：你当前打开的 DAX 查询、C# 脚本和 DAX 脚本的内容，以及每个打开的文档（包括 Pivot Grid）的错误和警告。写入：修改它们，并创建 C# 脚本和 DAX 查询。无法读取或修改 Pivot Grid 布局 |
| **宏** | 写 | 读：您的宏库，包括名称、描述和代码。写：此版本中没有其他工具 |

**写**（在下拉菜单中标记为**读/写**）包括读，而**模型数据**没有写级别。

**文档**默认为“写入”，这使代理能够创建选项卡并覆盖已打开的 DAX 查询、C# 脚本和 DAX 脚本的内容。代理不会运行它们，模型也不会发生变化。如果您在这些选项卡中保留未保存的工作，请将**文档**设置为**读**。

将这些权限提升到其默认值之上，可为代理提供更多访问权限：

- **模型数据 > 读取**将值从您的模型发送到您的代理，并通过代理发送到您的代理的提供商。当代理需要对照实际值检查结果时，授予此权限。
- **模型元数据 > 写入**允许代理通过 C# 脚本更改模型。请参阅[代理如何更改您的模型](#how-an-agent-changes-your-model) ，了解安全措施。

> [!IMPORTANT]
> 权限在服务器启动时读取，代理在连接时获取其工具列表。更改权限后，请停止并启动服务器，然后重新连接代理。在此之前，代理将保留其连接时生效的权限。

## 代理可以做什么

代理的工具取决于您的授权，下表列出了您可以请求的内容以及每个请求所需的授权。

| 请求 | 需要的授权 |
| -- | -- |
| 识别 Tabular Editor 实例及其已打开的模型 | 无 |
| 搜索 Tabular Editor 文档、博客、GitHub 问题和讨论 | 无 |
| 查找脚本 API：您正在运行的 Tabular Editor 版本中模型对象的属性、方法和签名 | 无 |
| 获取表、其列和度量值计数以及每个关系的概览 | **模型元数据 > 读取** |
| 获取命名对象的完整详细信息，包括表达式、描述、格式字符串和数据类型 | **模型元数据 > 读取** |
| 按名称、描述、DAX 或 M 表达式、格式字符串或注释搜索模型 | **模型元数据 > 读取** |
| 获取完整模型。这会使用大量令牌，工具描述会向代理发出警告 | **模型元数据 > 读取** |
| 查看在 TOM Explorer 中选定的对象 | **模型元数据 > 读取** |
| 获取 VertiPaq分析器统计数据：表大小、列基数和内存使用情况 | **模型元数据 > 读取** |
| 列出有效的 [Best Practice Analyzer](xref:best-practice-analyzer) 规则（包括您自己的规则），并运行分析 | **Best Practice Analyzer > 读取** |
| 在本地规则集中添加或更改规则 | **最佳实践分析器 > 写入** |
| 运行 DAX 查询并获取行。默认情况下，查询返回 100 行，最多返回 500 行 | **模型数据 > 读取**和**模型元数据 > 读取** |
| 列出模型的错误、警告和 Analysis Services 消息，首先列出根本原因 | **模型元数据 > 读取**。Analysis Services 错误的文本也需要**模型数据 > 读取** |
| 列出您的打开的 DAX 查询、C# 脚本、DAX 脚本和 Pivot Grid，以及活动文档和每个文档的错误和警告计数 | **模型元数据 > 读取** |
| 读取已打开的 DAX 查询、C# 脚本或 DAX 脚本的内容 | **文档 > 读取** |
| 读取一个已打开文档的错误和警告，包括服务器上次运行时返回的错误 | **文档 > 读取**。服务器错误的文本也需要**模型数据 > 读取** |
| 编辑已打开的 DAX 查询、C# 脚本或 DAX 脚本，或打开新的 C# 脚本或 DAX 查询以进行查看 | **文档 > 写入** |
| 读取你的宏库 | **宏 > 读取** |
| 更改模型。请参阅[代理如何更改您的模型](#how-an-agent-changes-your-model) | **模型元数据 > 写入** |

在提示中引用对象之前，请先在 TOM Explorer 中选择这些对象，例如，在询问“将这些对象格式化为一致”之前。要询问查询或脚本中的错误，请先将其选项卡设为活动文档，例如，在询问“为什么我在此查询中看到此错误？”之前。

在来自代理的 C# 脚本或 DAX 查询作为文档打开之前，Tabular Editor 会编译脚本或根据打开的模型验证查询，并将任何错误返回给代理。DAX 查询验证需要 Tabular Editor 连接到 Analysis Services 或 Power BI。

> [!NOTE]
> 查询数据需要实时连接，而 VertiPaq 统计信息需要连接或您已收集的统计信息。工具可用性在代理连接时设置，因此，如果您稍后连接模型，请重新连接代理。

## 代理如何更改您的模型

使用**模型元数据 > 写入**，代理通过在后台创建[C# 脚本](xref:csharp-scripts)来更改您的模型。Tabular Editor 编译脚本，检查其安全性，并针对打开的模型运行该脚本。

脚本可以执行 C# 脚本 API 支持的任何操作，例如添加度量值、列、计算组、透视、翻译、关系和刷新策略，或者批量重命名和格式化对象。代理运行的脚本具有以下属性：

- 其更改是一个撤消条目，即**C# 脚本 (MCP)**，而 **Ctrl+Z** 则撤消整个脚本。如果文档处于焦点状态，则按 **Ctrl+Z** 可撤消在文档中的键入操作。请先单击 TOM Explorer，或在“编辑”菜单中选择“撤消 C# 脚本 (MCP)”。请参阅[在文本编辑器中撤消](xref:undo-redo#undo-in-text-editors)。
- 如果脚本在执行过程中抛出异常，其所有更改都将回滚。
- 代理会收到一个列表，其中包含脚本添加、更改或删除的每个对象，以及脚本打印的所有内容。如果脚本引入或解决了 DAX 错误，结果也会列出这些错误，并按根本原因分组。
- 来自`Output`、`Info`、`Warning`或`Error`的消息作为结果的一部分返回给代理，且不会打开对话框。
- 在长时间调用运行时，会显示**请稍候**指示器，并且 Tabular Editor 中的点击操作将被忽略。
- 在您保存之前，已更改的对象和属性会在[TOM Explorer 和“属性”视图](xref:unsaved-changes)中标记。**显示更改**会将两个视图都筛选为更改，右键单击**还原**可撤消单个属性、单个对象或整个分支。

![“编辑”菜单在单个“撤消 C# 脚本 (MCP)”条目上打开，TOM Explorer 以绿色标记已添加的度量值，以橙色标记已更改的度量值，以红色带删除线的形式标记已删除的度量值，“属性”视图筛选出已更改的属性](~/content/assets/images/features/mcp-server/agent-change-review.png)

[AI 助手](xref:ai-assistant)聊天以相同的方式运行脚本，在撤销条目**C# 脚本（AI 助手）**下具有相同的单步撤销和回滚。代理脚本没有预览对话框，也没有**取消**。之后，在 TOM Explorer 和“属性”视图中查看它们的更改。

### 被阻止的操作

无论您是否授予权限，以下操作均被阻止：

- `ExecuteCommand` 用于运行原始 TMSL 或 XMLA，在代理运行的脚本中始终会失败。
- 访问文件系统、发出 Web 请求或引用外部程序集的代理脚本不会运行。此检查与 `BlockUnsafeScripts` 策略对已编译脚本进行的分析相同；请参阅[哪些操作被视为在模型范围内](xref:csharp-scripts#what-counts-as-staying-within-the-model)，以了解完整列表。脚本会发生什么情况取决于您的授权和策略：
  - 如果具有**文档 > 写入**权限，脚本将作为**代理脚本（审核）**文档打开，工具结果会指示代理让您审核并运行该脚本。
  - 如果没有**文档 > 写入**，脚本不会运行，也不会打开任何文档。
  - 如果设置了 `BlockUnsafeScripts` [策略](xref:policies)，脚本不会运行，也不会打开任何文档。
- 脚本中的 DAX 帮助程序需要**模型数据 > 读取**，与查询工具相同。

## 示例任务

### 修复最佳实践分析器违规项

打开模型并询问：

> 运行 Best Practice Analyzer，并告诉我哪些值得修复，最严重的先修复。

然后说“修复格式字符串违规”。如果授予**模型元数据 > 写入**权限，代理将编写一个脚本并运行它，并且已更改的对象在 TOM Explorer 中以橙色标记。[属性视图](xref:unsaved-changes)中的**显示更改**显示每个属性的更改前后的值。右键单击您不想要的任何更改上的**还原**，然后保存。

### 从规范添加度量值

将代理指向规范、工单或度量值定义电子表格：

> 将 requirements.md 中的度量值添加到“销售额”表中。遵循其中已使用的命名和格式字符串。

代理从其自己的工作区读取 `requirements.md`。

### 使用查询验证结果

在授予**模型数据 > 读取**权限后，代理可以运行 DAX 来检查其工作：

> 确认新的“利润率 %”度量值得出的总和与 2025 年的旧计算结果相同。

它编写DAX查询，运行该查询并比较结果。

### 编写脚本但不运行

借助**“文档”>“写入”**，代理可以将 C# 脚本或 DAX 查询放入一个文档中，由您自行审核和运行，例如，在运行之前检查更改，或稍后针对另一个模型运行：

> 为我编写一个脚本，将每个度量值的名称更改为首字母大写，但不要运行它。

脚本在 Tabular Editor 中以文档形式打开，并经过编译和安全检查。阅读后运行。

> [!TIP]
> 在任务之间进行审核和保存，以使每组未保存的更改都保持较小。

## 运行多个实例

每个 Tabular Editor 实例都在自己的端口上托管自己的服务器。要同时处理两个模型，请在各自的实例中打开每个模型，并将一个代理连接到每个模型。

对于第二个服务器，请启动第二个实例，打开**工具 > MCP 服务器……**，然后点击**启动服务器**。如果配置的端口已被占用，提示将提供接下来的 20 个端口中第一个空闲的端口；如果没有空闲端口，则会显示错误。您还可以在**工具 > 首选项 > AI 功能 > MCP 服务器**下设置另一个端口。

使用您自己的名称在您的代理中注册第二个端口，并在提示中为所指的实例命名。

## 在共享计算机上运行

服务器绑定到 `127.0.0.1`，其他机器无法访问。它还会拒绝带有非本地`Origin`标头的浏览器请求。

当**需要访问令牌**关闭时，计算机上的任何进程都可以在没有凭据的情况下进行连接。在有数人同时登录的主机上（例如远程桌面或 Citrix 服务器），这包括其他人员会话中的进程。

在**工具 > 首选项 > AI 功能 > MCP 服务器**下选择**需要访问令牌**，然后重启服务器。然后，代理必须出示服务器对话框中显示的令牌，没有令牌的请求将被拒绝。

选择**重新生成令牌**（令牌旁边的刷新按钮）以颁发新令牌，这将使现有注册失效并重启正在运行的服务器。如果令牌被泄露，请重新生成令牌并重新注册您的代理。管理员可以使用`RequireMcpAccessToken`策略使令牌对每个人都成为必选项，该策略还会锁定偏好设置。请参阅@policies。

## 哪些内容会离开您的计算机

当你使用 MCP 服务器时，Tabular Editor 不会联系 AI 提供商，而只会通过环回连接响应来自你电脑上进程的工具调用。代理搜索的知识库是随 Tabular Editor 一起提供的本地数据库，并从 Tabular Editor 的服务更新。

您的代理根据您的订阅和该提供商的条款向其提供商发送数据，并且代理的设置控制发送的内容。在**模型数据**默认为**拒绝**的情况下，代理不会从 Tabular Editor 接收任何数据值，Analysis Services 错误的文本将被替换为固定句子。要使代理接收的内容中不包含文件路径和服务器名称，请将**工具 > 首选项 > Tabular Editor > 用户界面**下的**模型源详细信息**设置为**仅名称**或**隐藏**。

请参阅 @security-privacy 了解更全面的情况，包括[AI 助手](xref:ai-assistant)，它直接调用提供商，并单独进行配置。

## 管理员控制

MCP 服务器默认开启，任何用户都可以将其关闭。管理员可以使用这些[策略](xref:policies)来控制 MCP 的运行方式：

| 策略 | 版本 | 功能 |
| -- | -- | -- |
| `DisableMcpServer` | 所有 | 删除 MCP 服务器。AI 助手聊天不受影响 |
| `DisableAi` | 所有 | 关闭所有 AI 功能，包括 MCP 服务器。如果 `REG_DWORD` 的值为 `1`，安装程序还会在新安装中不包含 AI 组件，并在升级时将其移除 |
| `RequireMcpAccessToken` | 所有 | 强制进行令牌身份验证并锁定首选项 |
| `DisableCSharpScripts` | 所有 | 阻止代理运行 C# 脚本并将脚本草拟到文档中。起草 DAX 查询以及所有只读工具均不受影响 |
| `BlockUnsafeScripts` | Enterprise | 对于 Tabular Editor 中的每个脚本，仅允许停留在模型内的脚本。访问文件、网络、其他进程或外部程序集的代理脚本不会运行，也不会打开任何审查文档 |
| `Max...` 和 `McpMax...` 权限限制 | Enterprise | 对每种资源设置上限。`Max...` 限制适用于 AI 助手和 MCP 服务器。`McpMax...` 限制仅适用于 MCP 服务器，并且只能降低 `Max...` 限制 |
| `AiAuditLogPath`、`AiAuditLogRetentionDays` | Enterprise | 设置[审计日志](xref:ai-audit-log)的位置和保留期 |
| `AiProvider` 和相关值 | Enterprise | 锁定 AI 助手的提供商。MCP 服务器不受影响 |

> [!WARNING]
> 如果没有 Enterprise 许可证，任何 Enterprise 策略值都会阻止 AI 助手和 MCP 服务器启动，并移除菜单项和状态栏指示器。`BlockUnsafeScripts` 值还会阻止所有脚本和宏，因此请仅在拥有 Enterprise 许可证的计算机上部署 Enterprise 策略（请参阅[没有 Enterprise Edition 会发生什么](xref:policies#what-happens-without-enterprise-edition)）。

在企业版中，Tabular Editor 会保留 AI 助手和 MCP 服务器活动的本地[审计日志](xref:ai-audit-log)，包括代理调用的每个工具以及其运行的任何 C# 脚本的完整文本。提示、回复和数据值不会被记录。在服务器对话框中**打开审计文件夹**，并在**工具 > 首选项 > AI 功能**中打开日志文件夹。在 Desktop 和 Business 版本中，不会记录任何内容，也不会显示这两个按钮。

请参阅@policies，了解完整列表、注册表布局和管理模板。

## 故障排除

| 您看到的内容 | 正在发生的情况 |
| -- | -- |
| 代理显示没有适用于 Tabular Editor 的工具 | 服务器未运行，或者代理在服务器运行之前已连接。检查状态栏是否显示“**MCP 已启动**”，然后重新连接代理 |
| 代理看不到您刚刚授予的权限 | 权限在服务器启动时读取，工具列表在连接时固定。停止并启动服务器，然后重新连接代理 |
| 代理在长时间中断后失去连接 | 如果 20 分钟内没有请求且没有打开的流，服务器将关闭会话。请重新连接代理 |
| 代理报告没有打开的模型 | 服务器独立于你的模型运行。在 Tabular Editor 中打开模型，然后再次提问。您无需重启任何内容 |
| 代理无法运行 DAX 查询 | **模型数据**默认设置为**拒绝**。查询还需要实时连接：对于从磁盘打开的模型，无论授予何种权限，查询工具都不可用 |
| 连接被拒绝，返回 401 | **需要访问令牌**已启用，但代理未发送令牌。再次从对话框中复制注册配置。其中包含令牌 |
| 端口已被占用 | 另一个 Tabular Editor 实例或其他应用程序正在使用该端口。接受提示中的下一个可用端口，并更新代理的注册信息。如果**自动启动 MCP 服务器**已启用，则启动时的冲突不会显示提示，且指示器显示**MCP 已停止** |
| **工具 > MCP 服务器...** 不在菜单中 | 在首选项中取消了选中 **启用 MCP 服务器**，未安装 AI 功能组件，管理员已设置 `DisableMcpServer` 或 `DisableAi`，或者在未获得相应许可证的计算机上设置了企业策略值。请参阅 @policies |
