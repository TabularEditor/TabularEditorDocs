代码操作 `DR013`（可读性） **简化否定逻辑**

## 描述

当逻辑表达式被取反时，通常将表达式改写为使用相反的运算符会更易读。

### 示例 1

将以下内容：

```dax
NOT([Sales Amount] = [Budget Amount])
```

改为：

```dax
[Sales Amount] <> [Budget Amount]
```

### 示例 2

将以下内容：

```dax
NOT([Cost Amount] < [Sales Amount])
```

改为：

```dax
[Cost Amount] >= [Sales Amount]
```

## 为什么 Tabular Editor 会建议这么做？

Negated logic can be harder to read and understand than non-negated logic. 通过移除否定（即 [`NOT`](https://dax.guide/NOT) 运算符）并反转比较运算符，代码会更简洁，也更容易阅读。
