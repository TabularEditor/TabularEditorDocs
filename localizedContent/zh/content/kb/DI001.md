代码操作 `DI001`（改进）**删除未使用的 VAR 变量**

## 描述

未在任何地方被引用的变量应当删除。

## 示例

将以下内容：

```dax
VAR _internetSalesTaxed = [Internet Sales] * 1.25
VAR _cogsTaxed = [Cost of Sales] * 1.25
VAR _internetSales = [Internet Sales]
RETURN _internetSalesTaxed - _cogsTaxed
```

改为：

```dax
VAR _internetSalesTaxed = [Internet Sales] * 1.25
VAR _cogsTaxed = [Cost of Sales] * 1.25
RETURN _internetSalesTaxed - _cogsTaxed
```

## 为什么 Tabular Editor 会这样建议？

未使用的变量会让你的代码更难阅读和理解。 By removing them, you make your code more concise and easier to maintain.

未使用的变量也表明代码可能存在错误，或者该变量原本用于某些用途，但后来相关内容被移除了。 By removing the variable, you avoid potential confusion for other developers who may be reading your code.
