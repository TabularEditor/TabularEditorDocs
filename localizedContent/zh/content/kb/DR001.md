代码操作 `DR001`（可读性）**转换为标量谓词**

## 描述

列筛选条件可以更简洁地写成标量谓词，无需显式使用 [`FILTER`](https://dax.guide/FILTER) 函数。

### 示例 1

将以下内容：

```dax
CALCULATE(
	[Invoice Amount],
	FILTER(ALL('Document'[Document Type]), 'Document'[Document Type] = "Sales Order")
)
```

改为：

```dax
CALCULATE(
	[Invoice Amount],
	'Document'[Document Type] = "Sales Order"
)
```

### 示例 2

将以下内容：

```dax
CALCULATE(
	[Invoice Amount],
	FILTER(VALUES('Document'[Document Type]), 'Document'[Document Type] = "Sales Order")
)
```

改为：

```dax
CALCULATE(
	[Invoice Amount],
	KEEPFILTERS('Document'[Document Type] = "Sales Order")
)
```

## 为什么 Tabular Editor 会建议这么做？

与显式使用 `FILTER` 函数相比，标量谓词是一种更简单、更精炼的写法（也可视为“语法糖”），用于表达列筛选条件。 By using a scalar predicate, the code becomes easier to read and understand, as it removes unnecessary complexity and makes the intent of the filter expression more clear.
