代码操作 `DR010`（可读性） **使用 COALESCE 重写**

## 描述

与其使用 [`IF`](https://dax.guide/IF) 从一组表达式中返回第一个非空白值，不如使用 [`COALESCE`](https://dax.guide/COALESCE) 函数。

### 示例

将以下内容：

```dax
IF(
    ISBLANK(Product[Long Description]), 
    Product[Short Description], 
    Product[Long Description]
)
```

改为：

```dax
COALESCE(Product[Long Description], Product[Short Description])
```

## 为什么 Tabular Editor 会这样建议？

`COALESCE` 函数能以更精简、更易读的方式从一组表达式中返回第一个非空白值。 By using `COALESCE`, the code becomes more readable and the intent of the expression is clearer.
