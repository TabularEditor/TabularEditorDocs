代码操作 `DR002`（可读性）**优先使用聚合函数而非迭代器函数**

## 描述

在可行的情况下，尽量用聚合函数替代迭代器函数，让代码更简单。

### 示例

将以下内容：

```dax
SUMX(Sales, Sales[Line Amount])
```

改为：

```dax
SUM(Sales[Line Amount])
```

## 为什么 Tabular Editor 会这样建议？

当你只需要对单一列的值进行聚合时，聚合函数（[`SUM`](https://dax.guide)、[`MIN`](https://dax.guide)、[`MAX`](https://dax.guide) 等） use simpler, more concise syntax, than their equivalent iterator functions ([`SUMX`](https://dax.guide), [`MINX`](https://dax.guide), [`MAXX`](https://dax.guide), etc.) and should be preferred to make the code more readable.
