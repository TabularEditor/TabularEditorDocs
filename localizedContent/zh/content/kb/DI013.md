代码操作 `DI013`（改进）：**使用除法运算符替代 DIVIDE**

## 描述

当 [`DIVIDE`](https://dax.guide/DIVIDE) 的第二个参数是非零常量时，使用除法运算符会更高效。

### 示例

将以下内容：

```dax
DIVIDE([Total Sales], 1.25)
```

改为：

```dax
[Total Cost] / 1.25
```

## 为什么 Tabular Editor 会这样建议？

`DIVIDE` 函数是一种稳健的方式来处理除以零的错误，因为当分母为零时，它会返回指定值；如果未指定，则返回 (Blank)。 However, when the denominator is guaranteed to be non-zero, such as when dividing by a (non-zero) constant, the division operator `/` is more efficient and easier to read. By using the division operator, the code becomes more concise and easier to understand.
