代码操作 `DI015`（改进）：**用 DIVIDE 替换 IF**

## 描述

使用 [`DIVIDE`](https://dax.guide/DIVIDE) 函数替代 [`IF`](https://dax.guide/IF)，更方便检查分母是否为零或空白。

### 示例 1

将以下内容：

```dax
IF([Total Cost] = 0, BLANK(), [Total Sales] / [Total Cost])
```

改为：

```dax
DIVIDE([Total Sales], [Total Cost])
```

### 示例 2

将以下内容：

```dax
IF([Total Cost] <> 0, [Total Sales] / [Total Cost])
```

改为：

```dax
DIVIDE([Total Sales], [Total Cost])
```

## 为什么 Tabular Editor 会建议这么做？

`DIVIDE` 函数能以更简洁、更易读的方式处理除零或空白值时的除法。 By using `DIVIDE`, you make your code more robust and easier to understand. Moreover, the `DIVIDE` function is more efficient than using `IF` to check for zero or blank values, as it only evaluates the denominator once.
