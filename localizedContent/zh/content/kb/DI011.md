代码操作 `DI011`（改进）**用 ISEMPTY 替换 COUNTROWS**

## 描述

在检查表是否为空时，使用 [`ISEMPTY`](https://dax.guide/ISEMPTY) 函数通常比统计表的行数更高效。

### 示例

将以下内容：

```dax
IF(COUNTROWS(Products) = 0, "No products", "Products exist")
```

改为：

```dax
IF(ISEMPTY(Products), "No products", "Products exist")
```

## 为什么 Tabular Editor 会这样建议？

在检查表是否为空时，DAX 中一个常见的反模式是使用 `COUNTROWS` 函数统计表的行数，然后将结果与零进行比较。 However, this pattern is inefficient, as it requires the engine to count all rows of the table, even if the only thing we are interested in is whether the table is empty or not.

By using the `ISEMPTY` function, the engine can stop counting rows as soon as it finds the first row, which is much more efficient. `ISEMPTY` 函数在表为空时返回 `TRUE`，否则返回 `FALSE`。这让它成为检查表是否为空时更高效、也更易读的写法。
