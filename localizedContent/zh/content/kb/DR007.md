代码操作 `DR007`（可读性） **简化 1 个变量代码块**

## 描述

仅包含一个 VAR 变量的变量块可以通过将表达式直接移到该块的 `RETURN` 部分来简化。 This assumes the variable is only referenced once without any context modifiers.

### 示例

将以下内容：

```dax
VAR _sales = [Total Sales]
RETURN
    _sales * 1.25
```

改为：

```dax
[Total Sales] * 1.25
```

## 为什么 Tabular Editor 会这样建议？

当 VAR 声明足够简单，并且该 VAR 变量在代码的 `RETURN` 部分仅被使用一次且没有任何上下文修饰时，就完全没有必要声明该变量。 This makes the code more concise and easier to read.
