代码操作 `DR004`（可读性） **为变量添加前缀**

## 描述

It is recommended to use a consistent prefix for variables, to more easily distinguish them from table references. 默认前缀为 `_`，但你可以在 **工具 > 偏好 > DAX编辑器 > 代码操作** 中配置要使用的前缀，以匹配你偏好的风格。

### 示例

将以下内容：

```dax
VAR sales = SUM('Internet Sales'[Sales Amount])
RETURN sales * 1.25;
```

改为：

```dax
VAR _sales = SUM('Internet Sales'[Sales Amount])
RETURN _sales * 1.25;
```

## 为什么 Tabular Editor 会这样建议？

此代码操作旨在提升 DAX 代码的可读性。 By using a consistent naming convention for your variables, it is easier to understand the purpose of each variable, and to distinguish between variables and tables.

此外，为变量使用特殊字符（例如下划线）作为前缀，有助于避免与表名发生命名冲突——以防未来在模型中添加了与变量同名的表。

## 备注

此代码操作还提供一个 **（所有出现位置）** 变体，当代码中有多个片段可以改进时会显示。 This variant will apply the code action to all relevant sections of the document at once.
