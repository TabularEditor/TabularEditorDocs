# Descargas de Tabular Editor 3

Esta página proporciona instrucciones de descarga e instalación de Tabular Editor 3.

## Última versión

Tabular Editor 3.27.1.1 (*[Notas de la versión](release-notes/3_27_1_1.md)*) se publica en dos compilaciones, una en .NET 10 y otra en .NET 8. Las dos compilaciones son *funcionalmente idénticas*. Al instalar una compilación, se reemplaza la otra; consulte [Cambiar entre los paquetes .NET 8 y .NET 10](xref:installation-activation-basic#switching-between-the-net-8-and-net-10-packages).

### En .NET 10 (recomendado)

Requiere [.NET Desktop Runtime 10](https://dotnet.microsoft.com/download/dotnet/10.0). El instalador `.exe` le ofrece descargarlo e instalarlo por usted; el archivo `.zip` portátil es autónomo y no necesita ningún tiempo de ejecución.

- Descargue [Tabular Editor 3.27.1.1 (64 bits)](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.Installer.x64.Net10.exe) *(recomendado)*
- Descargar [Tabular Editor 3.27.1.1 (ARM64)](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.Installer.ARM64.Net10.exe)
- Versiones portátiles: [x64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.x64.Net10.zip), [ARM64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.ARM64.Net10.zip)
- Versión MSI: [x64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.x64.Net10.msi), [ARM64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.ARM64.Net10.msi)

### En .NET 8

Para equipos que aún no pueden ejecutar el tiempo de ejecución de escritorio de .NET 10. Requiere [.NET Desktop Runtime 8](https://dotnet.microsoft.com/download/dotnet/8.0).

- Descargar [Tabular Editor 3.27.1.1 (64 bits)](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.Installer.x64.Net8.exe)
- Descargar [Tabular Editor 3.27.1.1 (ARM64)](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.Installer.ARM64.Net8.exe)
- Versiones portátiles: [x64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.x64.Net8.zip), [ARM64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.ARM64.Net8.zip)
- Versión MSI: [x64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.x64.Net8.msi), [ARM64](https://cdn.tabulareditor.com/files/archive/te3/3.27.1.1/TabularEditor.3.27.1.1.ARM64.Net8.msi)

> [!TIP]
> ¿No sabes cuál elegir? Elige el instalador de .NET 10 x64. Elige ARM64 solo en un PC basado en ARM y elige .NET 8 solo si tu organización no puede instalar el tiempo de ejecución de escritorio de .NET 10.

Consulte @system-requirements para ver la matriz completa y @release-history para ver las notas de la versión de esta y de todas las versiones anteriores.

## Instrucciones de instalación

1. Descarga el archivo instalador .exe.
2. Ejecuta el instalador .exe. El asistente de instalación te guiará a través del proceso de instalación.
3. Para obtener instrucciones sobre cómo activar el producto o cambiar una clave de licencia, consulte nuestra [guía de introducción](xref:getting-started).

No es necesario eliminar las instalaciones anteriores al actualizar a una versión más reciente de Tabular Editor 3.
