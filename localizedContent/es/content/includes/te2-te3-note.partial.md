> [!NOTE]
> Esta página trata sobre Tabular Editor 2, la versión gratuita y de código abierto de Tabular Editor. Tabular Editor 3 es la versión comercial. Añade un editor DAX con autocompletado, [consultas DAX](xref:dax-query), vista previa de tablas, diagramas, el [depurador DAX](xref:dax-debugger) e integración con [VertiPaq Analyzer](https://www.sqlbi.com/tools/vertipaq-analyzer/). @migrate-from-te2 compara los dos productos función por función.
>
> Tabular Editor 3 cuenta con un [servidor MCP](xref:mcp-server) que permite a los agentes de IA, como Claude Code, GitHub Copilot, Codex y Cursor, leer, consultar y modificar el modelo abierto.
>
> Los usuarios que lo utilicen por primera vez obtienen una [prueba gratuita de 30 días de Tabular Editor 3](https://tabulareditor.com/why-tabular-editor) con el conjunto de funciones de la edición Enterprise. Para la versión de prueba se necesita una dirección de correo electrónico válida, pero no una tarjeta de crédito. Consulta [Solicitar una licencia de prueba](xref:getting-started#requesting-a-trial-license).
