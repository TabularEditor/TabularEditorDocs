Acción de código `DR002` (Legibilidad) **Usar agregador en lugar de iterador**

## Descripción

Use una función de agregador en lugar de una función de iterador cuando sea posible, para simplificar el código.

### Ejemplo

Cambiar:
```dax
SUMX(Sales, Sales[Line Amount])
```
A:
```dax
SUM(Sales[Line Amount])
```

## ¿Por qué Tabular Editor sugiere esto?

Cuando solo necesitas agregar los valores de una sola columna, las funciones agregadoras ([`SUM`](https://dax.guide), [`MIN`](https://dax.guide), [`MAX`](https://dax.guide), etc.) utilizan una sintaxis más sencilla y concisa que sus funciones iteradoras equivalentes ([`SUMX`](https://dax.guide), [`MINX`](https://dax.guide), [`MAXX`](https://dax.guide), etc.) y deben preferirse para que el código sea más legible.
