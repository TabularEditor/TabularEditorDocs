# Duplicar objetos y cambiar el nombre de lotes
El menú contextual que aparece al hacer clic con el botón derecho en el árbol del Explorador le permite duplicar medidas y columnas. Los objetos duplicados tendrán sus nombres con el sufijo «copia». Además, puedes realizar cambios de nombre por lotes seleccionando varios objetos y haciendo clic con el botón derecho en el árbol del explorador.

![Cuadro de diálogo para cambiar nombres por lotes](~/content/assets/images/getting-started-te-03.png)

Puedes usar expresiones regulares para cambiar los nombres y, opcionalmente, elegir si también se deben cambiar los nombres de las traducciones.

Un objeto duplicado conserva todos los indicadores de error y advertencia que tenía el original, por lo que una copia de un objeto con una expresión no válida se marca como no válida de inmediato.

Si el original se muestra en más de una carpeta de visualización, la copia aparece en todas ellas y se selecciona después de crearse. Esto también se aplica cuando copia y pega un objeto.
